只出现一次的数字

📋 题目描述

给你一个 非空 整数数组 nums ，除了某个元素只出现一次以外，其余每个元素均出现两次。找出那个只出现了一次的元素。

你必须设计并实现线性时间复杂度的算法来解决此问题，且该算法只使用常量额外空间。

1 <= nums.length <= 3 × 104，-3 × 104 <= nums[i] <= 3 × 104，除某个元素仅出现一次外，其余均出现两次。

示例 1

输入：nums = [2,2,1]
输出：1

示例 2

输入：nums = [4,1,2,1,2]
输出：4

示例 3

输入：nums = [1]
输出：1

💭 模拟答题者思考

1. 暴力：用哈希表统计每个数出现次数，再找计数为 1 的数——O(n) 时间、O(n) 额外空间，满足时间但不满足「常量空间」。

2. 重复在哪里？成对出现的数字在「谁和谁相同」上重复，但我们只关心出现奇数次的那个数；配对信息可以用代数消掉，不必真的记频次表。

3. 异或性质：a ^ a = 0、a ^ 0 = a、交换结合律——把全部元素异或起来，成对相同的会相互抵消为 0，剩下就是单元素。

4. 手推 [4,1,2,1,2]：顺序异或可任意重排，等价于 4 ^ (1^1) ^ (2^2) = 4，与顺序无关。

5. 一遍扫完、只留一个整型变量，O(n) 时间、O(1) 空间，正好贴合题面要求。

🧠 变量语义（先读这三句再编码）

变量类型语义（三句法）
xorint定义：当前已扫描元素按位异或的累积结果，初值 0（异或幺元）
维护：同一数字出现偶数次异或后为 0，最终仅剩「只出现一次」的数字
更新：每扫到一个 nums[i]，令 xor ^= nums[i]
nums[i]int定义：当前待合并进累积异或的数组元素
维护：从左到右单次遍历，每个元素恰好参与一次异或
更新：循环变量 i 自增，直至 i == n

⌨️ 落码步骤

1. xor = 0

2. 遍历 nums，对每个 x 执行 xor ^= x

3. 返回 xor

💻 代码实现 

class Solution:
    def singleNumber(self, nums: list[int]) -> int:
        xor = 0
        for x in nums:
            xor ^= x
        return xor
class Solution {
public:
    int singleNumber(vector<int>& nums) {
        int xor = 0;
        for (int x : nums)
            xor ^= x;
        return xor;
    }
};
// 时间 O(n)，空间 O(1)

⚠️ 常见坑

❗ 本题假设「其余均出现两次」——若出现三次（见 LeetCode 137）则一次异或不够，需用出现次数对 3 取模的位计数法，别与 136 混用同一套模板。

❗ 用「异或和」当校验却忘记初始 xor=0：单独一个元素时输出应为该元素本身，初值错会导致整体偏移。

❗ 排序后相邻去重或双指针需要 O(n log n) 且思路复杂——能 O(n) XOR 时不要过度设计。

🔍 必测边界 Case

Case 1：单元素
nums = [1] → 1（直接返回唯一值）
Case 2：单元素在末尾
nums = [2,2,1] → 1
Case 3：单元素在开头
nums = [4,1,2,1,2] → 4
Case 4：含负数
nums = [-1,-1,5] → 5（异或对补码同样成立）
