#41 数组原地哈希 困难

缺失的第一个正数

📋 题目描述

给你一个未排序的整数数组 nums，请你找出其中没有出现的最小的正整数。

请你实现时间复杂度为 O(n) 并且只使用常数级别额外空间的解决方案。

示例 1

输入：nums = [1,2,0]
输出：3
范围 [1,2] 中的数字都在数组中，最小缺失正数是 3。

示例 2

输入：nums = [3,4,-1,1]
输出：2
1 在数组中，但 2 没有。

示例 3

输入：nums = [7,8,9,11,12]
输出：1
最小的正数 1 没有出现。

💭 模拟答题者思考

1. 我先想暴力：从 k=1 开始逐个检查是否在 nums 里，第一次不在的就是答案——正确但最坏要扫 O(n^2)。

2. 重复在哪里？对每个 k 都线性扫一遍数组，大量重复遍历。

3. 用哈希集合存所有正数，再扫 1,2,3... 找第一个缺失——时间 O(n) 但额外空间 O(n)，不满足题意。

4. 关键转化：长度为 n 时，答案只可能在 [1, n+1]。把数组本身当哈希表：值 v 应放在下标 v-1；通过交换把每个合法值「归位」，最后第一个 nums[i] != i+1 的位置就是答案 i+1。

5. 例 [3,4,-1,1]：n=4，交换后变为 [1,-1,3,4]，下标 1 处应为 2 却是 -1，返回 2。

🧠 变量语义（先读这三句再编码）

变量类型语义（三句法）
nint定义：数组长度，答案必在区间 [1, n+1] 内
维护：只关心 1..n 是否出现，大于 n 或非正数与答案无关
更新：初始化后不变；扫描阶段若 1..n 全在正确位置则答案为 n+1
iint定义：当前正在「归位」的下标
维护：从左到右推进；位置 i 应存放值 i+1
更新：当 nums[i] 已在 [1,n] 且已归位（或重复/越界）时 i++
nums[j]int[]定义：同时充当输入与「桶数组」——下标 j 表示正整数 j+1 的槽位
维护：若 nums[j] == j+1，说明 j+1 已出现；否则该槽位仍空
更新：当 1 <= nums[i] <= n 且 nums[i] != nums[nums[i]-1] 时，交换 nums[i] 与 nums[nums[i]-1]，把值送到其对应桶位

⌨️ 落码步骤

1. 令 n = len(nums)，答案搜索空间为 1..n+1

2. 对每个下标 i，当 1 <= nums[i] <= n 且 nums[i] != nums[nums[i]-1] 时，交换 nums[i] 与 nums[nums[i]-1]（把 nums[i] 送到值对应的桶位）

3. 交换条件中的 nums[i] != nums[nums[i]-1] 防止相同值无限互换（如两个 1）

4. 第二遍扫描：找第一个 i 使 nums[i] != i+1，返回 i+1

5. 若 1..n 全部归位，返回 n+1

💻 代码实现 

class Solution:
    def firstMissingPositive(self, nums: list[int]) -> int:
        n = len(nums)

        # 原地哈希：把值 v 交换到下标 v-1
        for i in range(n):
            while 1 <= nums[i] <= n and nums[i] != nums[nums[i] - 1]:
                target = nums[i] - 1
                nums[i], nums[target] = nums[target], nums[i]

        for i in range(n):
            if nums[i] != i + 1:
                return i + 1
        return n + 1
class Solution {
public:
    int firstMissingPositive(vector<int>& nums) {
        int n = nums.size();

        // 原地哈希：把值 v 交换到下标 v-1
        for (int i = 0; i < n; i++) {
            while (nums[i] >= 1 && nums[i] <= n && nums[i] != nums[nums[i] - 1]) {
                int target = nums[i] - 1;
                swap(nums[i], nums[target]);
            }
        }

        for (int i = 0; i < n; i++) {
            if (nums[i] != i + 1) return i + 1;
        }
        return n + 1;
    }
};
// 时间 O(n)，空间 O(1)

📈 复杂度分析

时间复杂度 O(n)（每个元素最多被交换到正确位置一次）
空间复杂度 O(1)（仅原地修改输入数组，不计输出）

⚠️ 常见坑

❗ 交换循环写 while nums[i] in [1,n] 却忘记 nums[i] != nums[nums[i]-1]：遇到重复值（如两个 1）会死循环。

❗ 用额外哈希表或排序：虽然能过部分用例，但违反 O(1) 额外空间要求。

❗ 第二遍扫描前误以为数组已排序：归位后顺序未必单调（如 [-1,3,1] 交换后为 [1,3,-1]），必须按下标检查 nums[i] == i+1。

🔍 必测边界 Case

Case 1：全为正且连续
nums = [1,2,0] → 3（1、2 都在，缺 3）
Case 2：缺 1
nums = [7,8,9,11,12] → 1（最小正数 1 未出现）
Case 3：含负数与越界值
nums = [3,4,-1,1] → 2（负数与 >n 的值不参与归位）
Case 4：单元素
nums = [1] → 2（1 在，答案为 n+1=2）
Case 5：全不在范围内
nums = [0,-1,100] → 1（没有任何 1..n 的值归位，第一个缺失为 1）
