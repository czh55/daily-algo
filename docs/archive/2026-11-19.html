📋 题目描述

在一条环路上有 n 个加油站，其中第 i 个加油站有汽油 gas[i] 升。

你有一辆油箱容量无限的汽车，从第 i 个加油站开往第 i+1 个加油站需要消耗汽油 cost[i] 升。你从其中的一个加油站出发，开始时油箱为空。

给定两个整数数组 gas 和 cost，如果你可以按顺序绕环路行驶一周，则返回出发时加油站的编号，否则返回 -1。如果存在解，则保证它是唯一的。

n == gas.length == cost.length，1 <= n <= 105，0 <= gas[i], cost[i] <= 104。

示例 1

输入：gas = [1,2,3,4,5], cost = [3,4,5,1,2]
输出：3
从 3 号站出发：到 4 站剩 8 升，经 0→1→2 再回到 3，全程油量始终非负，故起点为索引 3。

示例 2

输入：gas = [2,3,4], cost = [3,4,3]
输出：-1
任一起点都无法完成整圈：总补给不足以支付全程耗油。

💭 模拟答题者思考

1. 暴力：枚举起点 s = 0..n-1，模拟开车绕圈 n 步，每步加油再扣路段油耗；任一步油量为负则换起点，单次 O(n)，总 O(n²)。

2. 重复在哪里？固定起点时要一步步累加「净收益」gas[i]-cost[i]；换起点时又从 0 重算，大量前缀和被重复计算。

3. 全局必要条件：一圈总净油量 Σ(gas-cost) ≥ 0，否则无论如何都回不了起点；这是充分必要条件里的一半，可 O(n) 先判无解。

4. 贪心缩小起点：从左扫维护 tank 和候选 start。若开到 i 时 tank < 0，说明从 start..i 任一站出发都会在到达某站前断油（前面油量更少），故唯一可能起点只能 ≥ i+1，重置 tank 从新区间继续。

5. 扫完一圈且 total ≥ 0 时，最后留下的 start 即为答案；与「总净增非负 + 最后一小段前缀可行」合在一起，保证整圈可行。单次扫描 O(n)、O(1) 空间。

🧠 变量语义（先读这三句再编码）

变量类型语义（三句法）
totalint定义：全程 Σ(gas[i]-cost[i])，表示绕圈一圈后油箱相对出发时的净增量
维护：从左到右扫完所有站各累加一次差值，与起点无关
更新：每步 total += gas[i] - cost[i]；若最终 total < 0 则无解，直接返回 -1
tankint定义：从候选起点 start 出发，沿环路开到当前站 i 后车上的剩余汽油（尚未在 i 加油）
维护：仅当 tank ≥ 0 时说明「从 start 能顺利开到 i」；一旦变负则 start..i 内任一站作起点都不合法
更新：每站 tank += gas[i] - cost[i]；若 tank < 0 则 start = i+1 且 tank = 0
startint定义：当前唯一可能的合法出发站下标（题目保证若有解则唯一）
维护：初值为 0；每当 tank 跌破 0，说明上一段候选区间不可能，起点右移到下一站
更新：tank < 0 时设 start = i + 1；扫描结束后若 total ≥ 0 则返回 start

⌨️ 落码步骤

1. total = tank = 0，start = 0

2. 对 i in 0..n-1：d = gas[i] - cost[i]，total += d，tank += d

3. 若 tank < 0：start = i + 1，tank = 0（抛弃不可行前缀）

4. 若 total < 0 返回 -1，否则返回 start

💻 代码实现 

class Solution:
    def canCompleteCircuit(self, gas: list[int], cost: list[int]) -> int:
        total = tank = 0
        start = 0
        n = len(gas)
        for i in range(n):
            d = gas[i] - cost[i]
            total += d
            tank += d
            if tank < 0:
                start = i + 1
                tank = 0
        return start if total >= 0 else -1
class Solution {
public:
    int canCompleteCircuit(vector<int>& gas, vector<int>& cost) {
        long long total = 0, tank = 0;
        int start = 0;
        int n = gas.size();
        for (int i = 0; i < n; ++i) {
            int d = gas[i] - cost[i];
            total += d;
            tank += d;
            if (tank < 0) {
                start = i + 1;
                tank = 0;
            }
        }
        return total >= 0 ? start : -1;
    }
};
// 时间 O(n)，空间 O(1)；total 可用 long long 防溢出

⚠️ 常见坑

❗ 只判断 tank 中途非负就返回 start，却忘记先算全程 total：总补给为负时必为 -1，不能信最后一次 start。

❗ tank < 0 时只改 start 却不把 tank 清零：会把「上一段失败路径」的负油量带到新起点，误判后续站。

❗ 模拟时顺序搞错：应先到达站 i 并消耗 cost[i-1] 再在站 i 加 gas[i]；用差分 gas[i]-cost[i] 等价于「到站加油再走下一段」的环状扫描写法，不要对同一站重复加减。

🔍 必测边界 Case

Case 1：无解总量
gas=[2,3,4], cost=[3,4,3] → -1（total < 0）
Case 2：单站自环
gas=[5], cost=[4] → 0（加 5 耗 4 仍能回到 0 号站）
Case 3：起点不在 0
gas=[1,2,3,4,5], cost=[3,4,5,1,2] → 3
Case 4：首尾刚好平衡
每站 gas[i]==cost[i]，n>1 → 0（总净增为 0，从 0 出发可一圈）
Case 5：大 n 防溢出
Σ 可达 10^5×10^4；C++ 中 total 建议 long long
