📋 题目描述

按字典 wordList 完成从单词 beginWord 到单词 endWord 转化，一个表示此过程的 转换序列 是形式上像 beginWord -> s1 -> s2 -> ... -> sk 这样的单词序列，并满足：

  • 每对相邻的单词之间仅有单个字母不同。
  • 转换过程中的每个单词 si（1 <= i <= k）必须是字典 wordList 中的单词。注意，beginWord 不必在 wordList 中。
  • sk == endWord

给你 beginWord、endWord 和 wordList。找出并返回所有从 beginWord 到 endWord 的 最短转换序列（每条序列以单词列表形式返回）。若不存在，返回空列表。

示例 1

输入：beginWord = "hit", endWord = "cog", wordList = ["hot","dot","dog","lot","log","cog"]
输出：[["hit","hot","dot","dog","cog"],["hit","hot","lot","log","cog"]]
最短长度为 5，存在两条不同路径。

示例 2

输入：beginWord = "hit", endWord = "cog", wordList = ["hot","dot","dog","lot","log"]
输出：[]
endWord 不在字典中，无法完成转化。

💭 模拟答题者思考

1. 暴力：DFS 枚举所有 begin→end 的转化路径，再筛出最短的一批——路径数量可能指数级，且要跑完才知道最短长度，不现实。

2. 重复在哪里？题面要的是最短序列；无权图上的最短路天然适合 BFS 分层，先确定「最少几步」，再只枚举符合该步数的路径。

3. 建模：每个单词是点；差一位且在字典中的两词连边。求 beginWord 到 endWord 的所有最短路径。

4. 两阶段：先用层序 BFS 填 dist（在首次把 endWord 入队的那一层处理完后即可停）；再 DFS 从 beginWord 出发，只走 dist[nw]==dist[w]+1 的边收集全部最短路径。

5. 为什么 DFS 不会多走？若某边使距离增加超过最短层数，该分支不可能在相同步数内到达终点；与 BFS 标号一致即可保证只输出最短序列。

⌨️ 落码步骤

1. words = set(wordList)；若 endWord 不在集合中，返回 []

2. 实现 neighbors(w)：逐位替换 a–z，命中 words 则 yield

3. 层序 BFS：dist[beginWord]=0，按层扩展直到本层首次发现 endWord 后结束该层并 break

4. 若 endWord 不在 dist，返回 []

5. DFS(w, path)：到 endWord 则记录；否则对每个 nw∈neighbors(w) 且 dist[nw]==dist[w]+1 递归，回溯 pop

6. 从 [beginWord] 启动 DFS，返回 ans

from collections import deque

class Solution:
    def findLadders(self, beginWord: str, endWord: str, wordList: list[str]) -> list[list[str]]:
        words = set(wordList)
        if endWord not in words:
            return []

        L = len(beginWord)

        def neighbors(w: str):
            for i in range(L):
                for c in "abcdefghijklmnopqrstuvwxyz":
                    if c == w[i]:
                        continue
                    nw = w[:i] + c + w[i + 1 :]
                    if nw in words:
                        yield nw

        dist = {beginWord: 0}
        q = deque([beginWord])
        reached_end = False
        while q and not reached_end:
            for _ in range(len(q)):
                w = q.popleft()
                for nw in neighbors(w):
                    if nw not in dist:
                        dist[nw] = dist[w] + 1
                        if nw == endWord:
                            reached_end = True
                        q.append(nw)

        if endWord not in dist:
            return []

        ans: list[list[str]] = []

        def dfs(w: str, path: list[str]) -> None:
            if w == endWord:
                ans.append(path[:])
                return
            for nw in neighbors(w):
                if dist.get(nw) == dist[w] + 1:
                    path.append(nw)
                    dfs(nw, path)
                    path.pop()

        dfs(beginWord, [beginWord])
        return ans
class Solution {
public:
    vector<vector<string>> findLadders(string beginWord, string endWord, vector<string>& wordList) {
        unordered_set<string> words(wordList.begin(), wordList.end());
        if (!words.count(endWord)) return {};

        int L = (int)beginWord.size();
        auto neighbors = [&](const string& w) {
            vector<string> res;
            for (int i = 0; i < L; ++i) {
                for (char c = 'a'; c <= 'z'; ++c) {
                    if (c == w[i]) continue;
                    string nw = w;
                    nw[i] = c;
                    if (words.count(nw)) res.push_back(nw);
                }
            }
            return res;
        };

        unordered_map<string, int> dist{{beginWord, 0}};
        queue<string> q;
        q.push(beginWord);
        bool reached_end = false;
        while (!q.empty() && !reached_end) {
            int sz = (int)q.size();
            for (int t = 0; t < sz; ++t) {
                string w = q.front();
                q.pop();
                for (const string& nw : neighbors(w)) {
                    if (!dist.count(nw)) {
                        dist[nw] = dist[w] + 1;
                        if (nw == endWord) reached_end = true;
                        q.push(nw);
                    }
                }
            }
        }
        if (!dist.count(endWord)) return {};

        vector<vector<string>> ans;
        vector<string> path{beginWord};

        function<void(const string&)> dfs = [&](const string& w) {
            if (w == endWord) {
                ans.push_back(path);
                return;
            }
            for (const string& nw : neighbors(w)) {
                if (dist.count(nw) && dist[nw] == dist[w] + 1) {
                    path.push_back(nw);
                    dfs(nw);
                    path.pop_back();
                }
            }
        };
        dfs(beginWord);
        return ans;
    }
};
// 时间 O(N·L²·26)，空间 O(N·L)

⚠️ 常见坑

❗ 未先判断 endWord 是否在字典：与官方题意一致，不在则必须返回空列表，不能指望 BFS 自行发现。

❗ BFS 一遇到 endWord 就立刻全局 break 而未处理完当前层：可能导致某些同层最短路上的中间词尚未入队，dist 不完整，DFS 漏解。

❗ DFS 未沿 dist[nw]==dist[w]+1 约束扩展：会把更长路径也收集进来，或陷入错误分支；应用 BFS 距离做「剪枝」。

🔍 必测边界 Case

Case 1：终点不在字典

Case 2：多条最短路径

Case 3：无法连通
begin 与 end 不在同一连通分量 → []
Case 4：唯一最短路径
只有一条链时 answers 长度为 1
