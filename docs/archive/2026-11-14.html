#129 树前序递归 中等

求根节点到叶节点数字之和

📋 题目描述

给你一个二叉树的根节点 root，树中每个节点都存放有一个 0 到 9 之间的数字。

每条从根节点到叶节点的路径都代表一个数字：例如，路径 1 → 2 → 3 表示数字 123。计算从根节点到叶节点生成的所有数字之和。

叶节点 是指没有子节点的节点。树中节点数目在 [1, 1000]，节点值 0 ≤ val ≤ 9，树高不超过 10。

示例 1

输入：root = [1,2,3]
输出：25
路径 1→2 表示 12，路径 1→3 表示 13，总和 12 + 13 = 25。

示例 2

输入：root = [4,9,0,5,1]
输出：1026
路径 4→9→5 = 495，4→9→1 = 491，4→0 = 40，总和 495 + 491 + 40 = 1026。

💭 模拟答题者思考

1. 暴力直觉：枚举每条根到叶的路径，把节点值按顺序拼成字符串再转整数求和——正确，但字符串拼接与转换有额外开销。

2. 重复在哪里？多条路径共享祖先前缀（例如 4→9→5 与 4→9→1 共用「49」），适合在 DFS 下行时维护一个随深度递增的整数前缀，而不是每次从根重新拼。

3. 前序递推：到节点 u 时 prefix = prefix * 10 + u.val；若 u 为叶子，该路径只贡献这一个数 prefix；否则答案等于左右子树分别带着同一规则继续 DFS 后再相加。

4. 与 #112 路径和的对比：那里维护「还差多少」的 rem；这里维护「已拼成多少」的 prefix，同样在叶子才结算，中间不能提前加总。

5. 节点值 0–9、树高 ≤ 10，prefix 最大约 10 位，整型安全；每节点访问 O(1)，总时间 O(n)，栈深 O(h)。

🧠 变量语义（先读这三句再编码）

变量类型语义（三句法）
prefixint定义：从根沿当前 DFS 路径走到当前节点时，已拼接成的十进制数（高位在左）
维护：进入节点 u 时执行 prefix = prefix * 10 + u.val，与路径上各位左移拼接一致
更新：递归孩子时传入更新后的 prefix；回溯由递归返回自然消解，无需显式撤销
nodeTreeNode*定义：当前访问的节点，DFS 沿一条根到叶路径向下
维护：仅当左右皆空时，才把当前 prefix 计入总和；中间节点只向下传参、不结算
更新：先算本层 prefix，再递归 left / right，返回值相加得到子树贡献
sumNumbers(root) / dfs(node, prefix)int定义：以 node 为根的子树中，所有根到叶路径对应数字之和（子树内路径均共享当前已走前缀的祖先部分）
维护：空节点返回 0；答案 = 本层若是叶子则加 prefix，否则加左右子树的 DFS 返回值
更新：顶层 dfs(root, 0)，根前尚无数字故初始 prefix = 0

⌨️ 落码步骤

1. 定义 dfs(node, prefix)：若 node 为空返回 0

2. prefix = prefix * 10 + node.val

3. 若 node 无左右孩子（叶子），返回 prefix

4. 否则返回 dfs(left, prefix) + dfs(right, prefix)

5. 接口：return dfs(root, 0)

💻 代码实现 

class Solution:
    def sumNumbers(self, root: TreeNode | None) -> int:
        def dfs(node: TreeNode | None, prefix: int) -> int:
            if not node:
                return 0
            prefix = prefix * 10 + node.val
            if not node.left and not node.right:
                return prefix
            return dfs(node.left, prefix) + dfs(node.right, prefix)

        return dfs(root, 0)
class Solution {
public:
    int sumNumbers(TreeNode* root) {
        return dfs(root, 0);
    }

private:
    int dfs(TreeNode* node, int prefix) {
        if (!node) return 0;
        prefix = prefix * 10 + node->val;
        if (!node->left && !node->right)
            return prefix;
        return dfs(node->left, prefix) + dfs(node->right, prefix);
    }
};
// 时间 O(n)，空间 O(h)

⚠️ 常见坑

❗ 未到叶子就累加：只有一条边或到中间节点就把 prefix 加入答案，会把「前缀数字」误当成完整路径数（如只走到 1→2 就加 12，而右子树还有路径）。

❗ 混淆「节点值之和」与「路径拼接数」：本题是十进制拼接（1→2→3 为 123），不是 1+2+3=6。

❗ 单节点树：根即为叶子，应返回 root.val，而非 0；空指针由题目约束一般不会出现，但 dfs 仍应 return 0 保平安。

🔍 必测边界 Case

Case 1：单节点
root = [5] → 5
Case 2：官方示例 1
root = [1,2,3] → 25（12 + 13）
Case 3：官方示例 2
root = [4,9,0,5,1] → 1026
Case 4：路径含 0
root = [4,0] → 40（4→0 拼接为 40，不是 4+0）
Case 5：仅左链或仅右链
root = [1,2,null,3] → 123（唯一根到叶路径）
