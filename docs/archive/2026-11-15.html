被围绕的区域

📋 题目描述

给你一个 m x n 的矩阵 board，由若干字符 'X' 和 'O' 组成，捕获 所有 被围绕的区域：

  • 连接：一个单元格与水平或垂直方向上相邻的单元格连接。
  • 区域：连接所有 'O' 的单元格来形成一个区域。
  • 围绕：若区域中所有 'O' 都不在棋盘边缘，则该区域被包围，应整块由 'X' 围住。

通过原地将矩阵中应被捕获的 'O' 替换为 'X' 完成捕获；不需要返回值。矩阵规模 1 ≤ m, n ≤ 200。

示例 1

输入：board = [["X","X","X","X"],["X","O","O","X"],["X","X","O","X"],["X","O","X","X"]]
输出：[["X","X","X","X"],["X","X","X","X"],["X","X","X","X"],["X","O","X","X"]]
中间三块 O 被 X 完全围住应翻成 X；左下角与边界相连的 O 区域不能捕获。

示例 2

输入：board = [["X"]]
输出：[["X"]]

💭 模拟答题者思考

1. 暴力直觉：找出每个由 O 构成的连通块，若块内任一格在边界上则保留，否则整块改 X——正确，但要先找块、再判边界，写法繁琐。

2. 重复在哪里？「是否被围绕」等价于「是否与棋盘边缘连通」：与边界连通的 O 永远不会被捕获，只有完全在内部的 O 才需要翻成 X。

3. 正难则反：不从内部孤立块入手，而从四条边上的每个 O 出发做 DFS/BFS，把能到达的全部标为「安全」；这一步和 #200 岛屿数量是同一种网格淹没，只是种子点在边界上。

4. 第二遍线性扫描：仍是 O 的格子必为被围块 → 改 X；标成安全标记（如 #）的还原为 O；本来就是 X 的不动。

5. 每格最多被访问常数次，时间 O(m·n)；用临时字符代替 visited，额外空间主要为 DFS 栈 O(m·n) 最坏。

🧠 变量语义（先读这三句再编码）

变量类型语义（三句法）
board[r][c]char定义：格子当前字符，'X' / 'O'，搜索过程中临时用 '#' 标记「与边界连通、不可捕获」的 O
维护：仅会对起点为 'O' 的格子改值；边界 DFS 把连通的 O 标成 '#'，最终清扫把仍为 'O' 的翻 'X'、把 '#' 还原 'O'
更新：进入 DFS 时若为 'O' 先写 '#'；清扫阶段按字符分类一次性改写
dfs(r, c)void定义：从 (r,c) 出发，沿四邻域扩散，标记所有与当前「安全 O 分量」连通的格子
维护：越界、非 'O' 立即返回；否则标 '#' 并向四方向递归
更新：仅从四条边上的每个 'O' 启动，保证标记集合 = 与边界相接的全部 O
dirs(int,int)[]定义：四方向偏移 [(0,1),(0,-1),(1,0),(-1,0)]
维护：常量，对角线不算连通
更新：不更新

⌨️ 落码步骤

1. 若 board 为空直接返回；记 m, n

2. 定义 dfs(r,c)：越界或 board[r][c] != 'O' 返回；否则 board[r][c]='#'，四方向递归

3. 对四条边界上每个 board[r][c]=='O' 调用 dfs(r,c)

4. 双重循环每个格子：O → X，# → O

5. 原地修改，无返回值

💻 代码实现 

class Solution:
    def solve(self, board: list[list[str]]) -> None:
        if not board or not board[0]:
            return
        m, n = len(board), len(board[0])

        def dfs(r: int, c: int) -> None:
            if r < 0 or r >= m or c < 0 or c >= n or board[r][c] != "O":
                return
            board[r][c] = "#"
            dfs(r + 1, c)
            dfs(r - 1, c)
            dfs(r, c + 1)
            dfs(r, c - 1)

        for r in range(m):
            for c in range(n):
                if (r == 0 or r == m - 1 or c == 0 or c == n - 1) and board[r][c] == "O":
                    dfs(r, c)

        for r in range(m):
            for c in range(n):
                if board[r][c] == "O":
                    board[r][c] = "X"
                elif board[r][c] == "#":
                    board[r][c] = "O"

class Solution {
    int m, n;
public:
    void solve(vector<vector<char>>& board) {
        if (board.empty() || board[0].empty()) return;
        m = board.size();
        n = board[0].size();

        for (int r = 0; r < m; ++r) {
            for (int c = 0; c < n; ++c) {
                bool on_border = (r == 0 || r == m - 1 || c == 0 || c == n - 1);
                if (on_border && board[r][c] == 'O')
                    dfs(board, r, c);
            }
        }

        for (int r = 0; r < m; ++r) {
            for (int c = 0; c < n; ++c) {
                if (board[r][c] == 'O')
                    board[r][c] = 'X';
                else if (board[r][c] == '#')
                    board[r][c] = 'O';
            }
        }
    }

private:
    void dfs(vector<vector<char>>& board, int r, int c) {
        if (r < 0 || r >= m || c < 0 || c >= n || board[r][c] != 'O')
            return;
        board[r][c] = '#';
        dfs(board, r + 1, c);
        dfs(board, r - 1, c);
        dfs(board, r, c + 1);
        dfs(board, r, c - 1);
    }
};
// 时间 O(m·n)，空间 O(m·n)（递归栈最坏）

⚠️ 常见坑

❗ 正向找「被围块」容易重复造 visited 或并查集，思路绕；应牢记不可捕获 ⟺ 与边界 O 连通，从边界出发反标记。

❗ 清扫时误把临时标记当 X：标记字符必须与普通 X 区分（如 #），最后一轮要把 # 还原成 O。

❗ 单行或单列棋盘：整条边都是边界，该边上所有 O 都会先被标安全，不会被翻成 X。

🔍 必测边界 Case

Case 1：官方示例 1
4×4，中间被围 O 全变 X，左下 border O 保留
Case 2：全 X
board = [["X","X"],["X","X"]] → 不变
Case 3：单行全 O
board = [["O","O","O"]] → 仍全 O（均在边界）
Case 4：1×1 为 O
board = [["O"]] → [["O"]]
Case 5：内部孤岛
3×3 中心 O、四周 X → 中心变 X
