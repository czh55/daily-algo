📋 题目描述

给你一个整数数组 nums，除某个元素仅出现 一次 外，其余每个元素都恰出现 三次。请你找出并返回那个只出现了一次的元素。

你必须设计并实现线性时间复杂度、常数级空间的算法。

1 <= nums.length <= 3 × 104，-231 <= nums[i] <= 231 - 1，除某元素恰好出现 1 次外，其余均恰好出现 3 次。

示例 1

输入：nums = [2,2,3,2]
输出：3

示例 2

输入：nums = [0,1,0,1,0,1,99]
输出：99

💭 模拟答题者思考

1. 暴力：哈希表统计频次，找计数为 1 的键——O(n) 时间但 O(n) 空间，不满足「常数空间」。

2. 重复在哪里？成组出现三次的数字会在「第几次见到这一位」上重复；我们不需要记住是哪个数，只需知道每一位上 1 被累计了几次 mod 3。

3. 逐位思路：对 32 个二进制位分别统计全数组中该位为 1 的次数，再 % 3 拼回整数——O(32n)=O(n) 时间、O(1) 空间，但写 32 层循环臃肿。

4. 压缩：每一位独立地只有三种余数状态 {0,1,2}，用两个位掩码 ones（余 1）与 twos（余 2）并行编码全部 32 位；见到 num 时对所有位同时做三态转移，等价于「对该位计数 +num 的此位，再 mod 3」。

5. 与 #136 对比：两次 XOR 可消「出现 2 次」；出现 3 次要用 mod 3 计数，不能一股脑异或。

6. 扫完返回 ones：恰出现三次的数各 bit 会归零；只出现一次的那一项的余数 1 状态留在 ones 里，即答案。

🧠 变量语义（先读这三句再编码）

变量类型语义（三句法）
onesint（位掩码）定义：按位记录「该二进制位在已扫描元素中出现次数 mod 3 的余数为 1」的位集合，初值 0
维护：出现 3 次的数每位都会经历 0→1→2→0，最终只有「出现 1 次」的数会在 ones 上留下该位的 1
更新：见每轮 num 后 ones = (ones ^ num) & ~twos
twosint（位掩码）定义：按位记录「该位出现次数 mod 3 的余数为 2」的位集合，初值 0
维护：与 ones 共同参与三态有限自动机，禁止同一位同时在两者中为 1（用 & ~ 互斥）
更新：见每轮 num 后 twos = (twos ^ num) & ~ones（须在更新 ones 之后）
numint定义：当前扫入的数组元素
维护：从左到右单次遍历，每个元素驱动一次状态转移
更新：循环取下一位，直至数组结束

⌨️ 落码步骤

1. ones = 0，twos = 0

2. 遍历每个 num：

3.    ones = (ones ^ num) & ~twos

4.    twos = (twos ^ num) & ~ones（顺序固定：先算 ones 再算 twos）

5. 返回 ones

💻 代码实现 

class Solution:
    def singleNumber(self, nums: list[int]) -> int:
        ones = 0  # 各位 mod3 余 1 的位掩码
        twos = 0  # 各位 mod3 余 2 的位掩码
        for num in nums:
            ones = (ones ^ num) & ~twos
            twos = (twos ^ num) & ~ones
        return ones
class Solution {
public:
    int singleNumber(vector<int>& nums) {
        int ones = 0, twos = 0;
        for (int num : nums) {
            ones = (ones ^ num) & ~twos;
            twos = (twos ^ num) & ~ones;
        }
        return ones;
    }
};
// 时间 O(n)，空间 O(1)

⚠️ 常见坑

❗ 与 #136 混淆：本题是「其余出现三次」，全体 XOR 无法抵消，必须用 mod 3 位计数或 ones/twos 状态机。

❗ 两行更新的顺序不能反：须先 ones = (ones ^ num) & ~twos，再 twos = (twos ^ num) & ~ones，否则互斥约束被破坏。

❗ 忘记 & ~twos / & ~ones：缺了掩码会让同一位在 ones 与 twos 同时为 1，状态非法。

❗ 返回值写成 ones ^ twos 或只盯 twos：本题最终答案就是扫完后的 ones。
