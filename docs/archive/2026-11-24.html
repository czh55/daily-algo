📋 题目描述

给你一个字符串 s 和一个字符串列表 wordDict 作为字典。如果可以利用字典中出现的一个或多个单词拼接出 s 则返回 true。

注意：不要求字典中出现的单词全部都使用，并且字典中的单词可以重复使用。

1 <= s.length <= 300，1 <= wordDict.length <= 1000，1 <= wordDict[i].length <= 20，s 与词典项仅由小写英文字母组成，词典中单词互不相同。

示例 1

输入：s = "leetcode", wordDict = ["leet","code"]
输出：true
由 "leet" 与 "code" 拼接而成。

示例 2

输入：s = "applepenapple", wordDict = ["apple","pen"]
输出：true
由 "apple" "pen" "apple" 拼接；词典单词可重复使用。

示例 3

输入：s = "catsandog", wordDict = ["cats","dog","sand","and","cat"]
输出：false
无法用给定单词拼出整串。

💭 模拟答题者思考

1. 暴力：回溯枚举 s 上所有切分点，检查每一段是否都在词典里——指数级分支（切点组合），n≤300 会 TLE。

2. 重复在哪里？判断「s[i:] 能否拼好」时，先试某段 w 再递归余下后缀——同一后缀被不同前缀重复求解，应记忆化而非裸 DFS。

3. 转化：只问「能否」，不必输出方案。定义 dp[i] = 前缀 s[0:i) 可否被拼接。若存在切分点 j 使 dp[j] 为真且尾段 s[j:i] 是词典词，则 dp[i] 为真——典型一维 DP。

4. 手推 s="leetcode"，词典 leet, code：dp[0]=True；i=4 时 j=0，"leet" 在集内 → dp[4]=True；i=8 时 j=4，"code" 在集内且 dp[4] → dp[8]=True。

5. 反面 catsandog：虽有 cat/sand 等词，但不存在让整串结束的切法（经典迷惑：cats+and+og 中 og 不在词典），dp[n] 保持 false。

🧠 变量语义（先读这三句再编码）

变量类型语义（三句法）
word_setset[str]定义：字典 wordDict 转成的集合，用于 O(1) 判断某子串是否在词典中
维护：构造后只读，遍历过程中不变
更新：预处理 word_set = set(wordDict) 一次性建成
dp[i]bool[n+1]定义：s[0:i)（长度为 i 的前缀）能否被词典单词顺序拼接成整段
维护：dp[0]=True（空前缀）；目标答案为 dp[n]，n=len(s)
更新：枚举最后一段左端点 j：若 dp[j] 且 s[j:i] ∈ word_set，则令 dp[i]=True
i / jint定义：i 为当前考察的前缀右边界（不含），j 为「最后一段单词」的起始下标
维护：外层 i 从 1 增至 n；内层 j 从 0 到 i-1
更新：找到任一合法 j 即可置 dp[i]，不必枚举全部切法

⌨️ 落码步骤

1. word_set = set(wordDict)，n = len(s)，dp = [False] * (n + 1)，dp[0] = True

2. 对 i 从 1 到 n：初始化 dp[i] = False（若找到合法切分再置真）

3. 内层 j 从 0 到 i-1：若 not dp[j] 跳过；否则检查 s[j:i] in word_set

4. 若子串在词典中：dp[i] = True 并 break（本题只需判断存在性）

5. 返回 dp[n]

💻 代码实现 

class Solution:
    def wordBreak(self, s: str, wordDict: List[str]) -> bool:
        word_set = set(wordDict)
        n = len(s)
        dp = [False] * (n + 1)
        dp[0] = True
        for i in range(1, n + 1):
            for j in range(i):
                if not dp[j]:
                    continue
                if s[j:i] in word_set:
                    dp[i] = True
                    break
        return dp[n]
class Solution {
public:
    bool wordBreak(string s, vector<string>& wordDict) {
        unordered_set<string> wordSet(wordDict.begin(), wordDict.end());
        int n = s.size();
        vector<bool> dp(n + 1, false);
        dp[0] = true;
        for (int i = 1; i <= n; ++i) {
            for (int j = 0; j < i; ++j) {
                if (!dp[j]) continue;
                if (wordSet.count(s.substr(j, i - j))) {
                    dp[i] = true;
                    break;
                }
            }
        }
        return dp[n];
    }
};
// 时间 O(n²·L)，空间 O(n + |wordDict|)

📈 复杂度分析

时间复杂度 O(n² × L)（n 为串长，L 为字典单词最大长度；子串判等每次 O(L)）
空间复杂度 O(n + M)（dp 数组 O(n)，字典哈希集 O(M)）

⚠️ 常见坑

❗ 下标与长度混淆：dp[i] 表示长度为 i 的前缀 s[0:i)，不是「第 i 个字符」；答案应读 dp[len(s)]，不是 dp[n-1]。

❗ 忘记 dp[0]=True：空前缀是合法起点，否则任何整词匹配都无法从 j=0 转移。

❗ 误以为词典单词必须各用一次：题目允许重复与未使用；只需存在一种拼接方式，与 Word Break II 求全部方案不同。

🔍 必测边界 Case

Case 1：整串即一个词
s = "a", wordDict = ["a"] → true
Case 2：重复使用同一词
s = "aaaa", wordDict = ["aa"] → true（aa+aa）
Case 3：无解但有前缀词
s = "catsandog" → false（官方示例 3）
Case 4：长串由多段拼成
s = "applepenapple" → true（官方示例 2）
Case 5：词典不含任何子串
s = "ab", wordDict = ["cd"] → false
