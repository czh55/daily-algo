📋 题目描述

给定一个数组，它的第 i 个元素是一支给定的股票在第 i 天的价格。

设计一个算法来计算你所能获取的最大利润。你最多可以完成 两笔 交易。

注意：你不能同时参与多笔交易（你必须在再次购买前出售掉之前的股票）。

示例 1

输入：prices = [3,3,5,0,0,3,1,4]
输出：6
第 4 天（价 0）买入、第 6 天（价 3）卖出，利润 3；第 7 天（价 1）买入、第 8 天（价 4）卖出，利润 3；合计 6。

示例 2

输入：prices = [1,2,3,4,5]
输出：4
一次交易 1 买 5 卖即可达上限 4；两笔限额并未迫使拆成更低利润。

示例 3

输入：prices = [7,6,4,3,1]
输出：0
全程下跌，不交易最优。

示例 4

输入：prices = [1]
输出：0

💭 模拟答题者思考

1. 暴力：枚举两笔不相交交易的买/卖日四元组，或 DFS 所有买卖序列；交易日多时至 O(n⁴) 或指数级，不可行。

2. 重复在哪里？「到第 i 天、已用 k 笔交易、当前持仓/现金」是经典子问题——与 #121（k=1）一脉相承，本题 k=2。

3. 压缩状态：只需四个标量——第一次买/卖的最优、在第一次利润确定后第二次买/卖的最优；扫描顺序上 sell1 先于 buy2 更新，保证两笔不交叠。

4. 与 #122 对比：#122 可无限笔且贪心吃相邻涨幅；本题至多两笔，不能把全部上涨段都拆开，必须用 DP 在「一笔 vs 两笔」间权衡。

5. 边界：0 笔或 1 笔交易也可能最优，sell2 初值 0、且始终 max 更新，自然涵盖「只做一笔」或「不做」。

🧠 变量语义（先读这三句再编码）

变量类型语义（三句法）
buy1int定义：完成第 1 笔买入后，为使「第 1 次卖出」利润最大的最优买入价（等价于历史上最低价）
维护：扫过 prices[0..i] 后，buy1 = min(此前 buy1, prices[i])
更新：每遇到更低股价就降低 buy1
sell1int定义：至多完成 1 笔交易时，到当前日可获得的最大利润
维护：sell1 = max(sell1, prices[i] - buy1)
更新：每天用当前价尝试「在 buy1 买入、今日卖出」并取历史最优
buy2int定义：在第 1 笔利润已锁定为 sell1 的前提下，第 2 笔买入的最小净成本（二次买入价减去已赚的 sell1）
维护：buy2 = min(buy2, prices[i] - sell1)
更新：sell1 越大，二次买入的「有效成本」越低
sell2int定义：至多完成 2 笔交易时，到当前日可获得的最大总利润（最终答案）
维护：sell2 = max(sell2, prices[i] - buy2)
更新：在二次买入成本为 buy2 时，用今日价尝试完成第 2 笔卖出

⌨️ 落码步骤

1. 初始化 buy1 = prices[0]，sell1 = sell2 = 0，buy2 = prices[0]（与首价对齐，稍后会被 min 修正）

2. 从 i=1 到 n-1 扫描 prices[i]

3. 更新第一笔：buy1 = min(buy1, price)，sell1 = max(sell1, price - buy1)

4. 更新第二笔：buy2 = min(buy2, price - sell1)，sell2 = max(sell2, price - buy2)

5. 返回 sell2

💻 代码实现 

class Solution:
    def maxProfit(self, prices: list[int]) -> int:
        if not prices:
            return 0
        buy1 = buy2 = prices[0]
        sell1 = sell2 = 0
        for price in prices[1:]:
            buy1 = min(buy1, price)
            sell1 = max(sell1, price - buy1)
            buy2 = min(buy2, price - sell1)
            sell2 = max(sell2, price - buy2)
        return sell2
class Solution {
public:
    int maxProfit(vector<int>& prices) {
        if (prices.empty()) return 0;
        int buy1 = prices[0], buy2 = prices[0];
        int sell1 = 0, sell2 = 0;
        for (int i = 1; i < (int)prices.size(); i++) {
            int price = prices[i];
            buy1 = min(buy1, price);
            sell1 = max(sell1, price - buy1);
            buy2 = min(buy2, price - sell1);
            sell2 = max(sell2, price - buy2);
        }
        return sell2;
    }
};
// 时间 O(n)，空间 O(1)

⚠️ 常见坑

❗ 状态更新顺序：同一轮里应先推 sell1 再算 buy2，否则会把「尚未发生的第一次卖出」混进第二笔。

❗ 勿直接套用 #122 的相邻正差累加：两笔上限会漏掉「一段大跌后两段独立上涨」这类最优划分。

❗ buy2 = price - sell1 可能为负：这是净成本，min 保留更小（更有利）的二次买入时机，不要当成非法。

🔍 必测边界 Case

Case 1：单元素
prices = [1] → 0（无法完成买卖）
Case 2：单调上涨
prices = [1,2,3,4,5] → 4（一笔即最优，sell2 与 sell1 同为 4）
Case 3：单调下跌
prices = [7,6,4,3,1] → 0
Case 4：两笔分离峰值
prices = [3,3,5,0,0,3,1,4] → 6（0 附近买、两段各赚 3）
Case 5：第二笔无益
prices = [1,5] → 4（只做一笔；sell2 不会低于 sell1 逻辑下的最优）
