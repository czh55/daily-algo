📋 题目描述

给定一个字符串 s 和一个字符串字典 wordDict，在 s 中插入空格来构建句子，使句子中所有单词都在词典中。以任意顺序返回所有这些可能的句子。

注意：词典中的同一个单词可能在分段中被重复使用多次；词典内单词互不相同。

1 <= s.length <= 20，1 <= wordDict.length <= 1000，1 <= wordDict[i].length <= 10，s 与词典项仅由小写英文字母组成。

示例 1

输入：s = "catsanddog", wordDict = ["cat","cats","and","sand","dog"]
输出：["cats and dog","cat sand dog"]
两种合法切分：cats|and|dog 与 cat|sand|dog。

示例 2

输入：s = "pineapplepenapple", wordDict = ["apple","pen","applepen","pine","pineapple"]
输出：["pine apple pen apple","pineapple pen apple","pine applepen apple"]
词典词可重复出现在方案中（如两个 apple）。

示例 3

输入：s = "catsandog", wordDict = ["cats","dog","sand","and","cat"]
输出：[]
无完整切分方案（与 #139 判断为 false 的同一串）。

💭 模拟答题者思考

1. 暴力：回溯每一刀是否落在合法词边界上，凑齐整条路径后压成一句——与 #131 分割回文串同形，但合法性改成「段 ∈ 词典」；须收集所有方案，不能只求真。

2. 重复在哪里？不同前缀切法会反复求解「s[k:] 能拼成哪些句子？」——同一后缀状态应记忆化，而非裸回溯指数爆炸。

3. 与 #139 关系：#139 用 dp[i]=bool 只问「前缀可否」；本题要列出句子，令 memo[i] = list[str] 表示后缀 s[i:] 的全部句子，由首词 + 递归子后缀拼接。

4. 手推 s="catsanddog"：dfs(0) 先试 "cats" → dfs(7) 得 "and dog" → "cats and dog"；再试 "cat" → dfs(3) 经 "sand"、"dog" 得 "cat sand dog"。两路径互不干扰因 memo 缓存各起点。

5. |s|≤20 保证输出与搜索可控；若忘记缓存或拼接空格，易 WA/TLE。

🧠 变量语义（先读这三句再编码）

变量类型语义（三句法）
word_setset[str]定义：词典转集合，O(1) 判断某子串是否为整词
维护：构造后只读
更新：word_set = set(wordDict) 预处理一次
memo[i]dict[int, list[str]]定义：子串 s[i:] 能形成的全部句子列表（各词间已含单空格）
维护：仅当某 i 首次展开完毕才写入，避免重复 DFS 同一后缀
更新：dfs(i) 结束时 memo[i] = 本层拼出的 sentences；无解后缀记 [] 亦缓存
i / jint定义：i 为当前待切后缀起点；j 为「第一段词」的右边界（不含）
维护：每选中合法词 s[i:j] 后子问题从 dfs(j) 继续
更新：内层枚举 j，仅 s[i:j] in word_set 才拼接 词 + 空格 + 后缀句
sentenceslist[str]定义：dfs(i) 当次调用返回的、以 s[i:] 为 remainder 的全部完整句子
维护：由首词与 memo[j]（或 dfs(j)）笛卡尔式拼接而得
更新：i==n 时返回 [""] 作为空后缀占位，便于上层拼接

⌨️ 落码步骤

1. word_set = set(wordDict)，n = len(s)，memo: dict[int, list[str]] = {}

2. 定义 dfs(i)：若 i in memo 直接返回；若 i == n 返回 [""]

3. 初始化本层 res = []，j 从 i+1 到 n，令 word = s[i:j]

4. 若 word not in word_set 跳过；否则对 dfs(j) 的每个后缀句 tail，拼接 word + (" " + tail if tail else "") 加入 res

5. memo[i] = res 并返回；入口 return dfs(0)

💻 代码实现 

class Solution:
    def wordBreak(self, s: str, wordDict: List[str]) -> List[str]:
        word_set = set(wordDict)
        n = len(s)
        memo: dict[int, list[str]] = {}

        def dfs(i: int) -> list[str]:
            if i in memo:
                return memo[i]
            if i == n:
                return [""]
            res: list[str] = []
            for j in range(i + 1, n + 1):
                word = s[i:j]
                if word not in word_set:
                    continue
                for tail in dfs(j):
                    sent = word if not tail else f"{word} {tail}"
                    res.append(sent)
            memo[i] = res
            return res

        return dfs(0)
class Solution {
public:
    vector<string> wordBreak(string s, vector<string>& wordDict) {
        unordered_set<string> wordSet(wordDict.begin(), wordDict.end());
        int n = s.size();
        unordered_map<int, vector<string>> memo;

        function<vector<string>(int)> dfs = [&](int i) -> vector<string> {
            if (memo.count(i)) return memo[i];
            if (i == n) return {""};
            vector<string> res;
            for (int j = i + 1; j <= n; ++j) {
                string word = s.substr(i, j - i);
                if (!wordSet.count(word)) continue;
                for (const string& tail : dfs(j)) {
                    if (tail.empty()) res.push_back(word);
                    else res.push_back(word + " " + tail);
                }
            }
            return memo[i] = res;
        };

        return dfs(0);
    }
};
// 时间：输出规模 × 切点枚举；空间：memo + 答案

📈 复杂度分析

时间复杂度 O(N² · M) 枚举切点 + 输出规模（最坏 O(n · 2ⁿ) 种句子；|s|≤20 可接受）
空间复杂度 O(N² · M)（记忆化存每个后缀的全部句子；M 为词典单词总长上界）

⚠️ 常见坑

❗ 照搬 #139 只返回 bool：本题要列出全部句子，状态应是「后缀 → 句子列表」而非单个真假。

❗ 拼接空格：空后缀 tail=="" 时不能再加前导空格，否则多一个空格导致与判题不一致。

❗ 未记忆化：同一 i 会被多种首词重复展开，|s|≤20 时仍可能 TLE；务必 memo[i] 缓存含空列表的结果。

🔍 必测边界 Case

Case 1：无解
s = "catsandog" → []（官方示例 3）
Case 2：整串一词
s = "a", wordDict = ["a"] → ["a"]
Case 3：前缀重叠词
cat / cats 同时存在 → 分支互不剪枝，答案含多句
Case 4：重复用同一词典词
pineapplepenapple → 方案中可出现两个 apple
Case 5：最长 |s|=20
依赖 memo，避免对同一后缀裸 DFS
