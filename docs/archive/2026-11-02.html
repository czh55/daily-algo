📋 题目描述

给定一个普通二叉树（不要求满/完美），节点定义含 val, left, right, next。请填充每个 next，使其指向同一层的下一个右侧节点；若无右侧邻居则置 NULL。初始时所有 next 均为 NULL。

进阶：只能使用常量级额外空间（递归栈不算额外空间）。

节点数 [0, 6000]，-100 ≤ val ≤ 100。

示例 1

输入：root = [1,2,3,4,5,null,7]
输出：[1,#,2,3,#,4,5,7,#]
第 2 层只有 2、3；第 3 层 4→5→7 横向串联，缺左子树的节点不参与该层 next 链。

示例 2

输入：root = []
输出：[]

💭 模拟答题者思考

1. 暴力直觉：层序 BFS，队列按层收集节点，每层从左到右 prev.next = node——正确，但队列最坏 O(n) 额外空间，不满足进阶 O(1) 要求。

2. 重复在哪里？#116 完美树能用 leftmost.left 直接跳到下一层最左，因为每层满且连续；本题子树可能缺失（如节点 3 只有右孩子 7），下一层最左不能简单用 leftmost.left 推断。

3. 关键观察：处理第 k 层时，第 k 层的 next 已连成链表，可用 curr = curr.next 扫层；同时在扫的过程中，把第 k+1 层所有实际存在的孩子按从左到右顺序挂到一条新链表上。

4. 手推示例 1 第 2 层：curr=2 时追加 4、5；curr=3 时追加 7，得到下一层链 4→5→7。第 3 层只有 4→5→7 三个节点，各自 next 在本层内连好即可。

5. 外层 while leftmost、内层沿 next 扫层并用 dummy/tail 建下一层链，每个节点常数工作 O(n)；除常数哨兵外无队列，空间 O(1)。

🧠 变量语义（先读这三句再编码）

变量类型语义（三句法）
leftmostNode*定义：当前正在处理的层的最左节点，初始为 root
维护：处理完本层后，下一层链表已由 dummy 串好，最左节点即 dummy.next
更新：每层结束 leftmost = dummy.next；若为 NULL 则没有更深层
currNode*定义：沿本层已填好的 next 从左到右行走的指针
维护：每访问一个节点，把其存在的左/右孩子按层序追加到「下一层链表」tail 之后
更新：curr = curr.next，直到本层扫完
dummy / tailNode*定义：dummy 是下一层链表的哨兵头；tail 指向已串好的最后一个孩子节点
维护：每遇到 curr.left 或 curr.right，令 tail.next = 该孩子 并后移 tail
更新：进入新的一层前重置 dummy = Node(0)、tail = dummy（常数个哨兵，不占 O(n) 容器）

⌨️ 落码步骤

1. 若 root 为空，直接返回

2. leftmost = root；当 leftmost 非空时处理一层

3. 新建 dummy 哨兵与 tail = dummy，curr = leftmost

4. 内层沿 curr.next：若 curr.left 存在则挂到 tail 后；若 curr.right 存在同理；curr = curr.next

5. 本层扫完后 leftmost = dummy.next，进入下一层（可能为空链，循环结束）

6. 返回 root

💻 代码实现 

class Solution:
    def connect(self, root: "Optional[Node]") -> "Optional[Node]":
        if not root:
            return None
        leftmost = root
        while leftmost:
            dummy = Node(0)
            tail = dummy
            curr = leftmost
            while curr:
                if curr.left:
                    tail.next = curr.left
                    tail = tail.next
                if curr.right:
                    tail.next = curr.right
                    tail = tail.next
                curr = curr.next
            leftmost = dummy.next
        return root
class Solution {
public:
    Node* connect(Node* root) {
        if (!root) return nullptr;
        Node* leftmost = root;
        while (leftmost) {
            Node dummy(0);
            Node* tail = &dummy;
            Node* curr = leftmost;
            while (curr) {
                if (curr->left) {
                    tail->next = curr->left;
                    tail = tail->next;
                }
                if (curr->right) {
                    tail->next = curr->right;
                    tail = tail->next;
                }
                curr = curr->next;
            }
            leftmost = dummy.next;
        }
        return root;
    }
};
// 时间 O(n)，空间 O(1)

📈 复杂度分析

时间复杂度 O(n)
空间复杂度 O(1)（已建 next 链层序 + 常数哨兵；BFS 队列版 O(w)）

⚠️ 常见坑

❗ 直接套用 #116 的 curr.left.next = curr.right：非完美树同一父节点的左右孩子可能只存在一个，且跨父连接需跳过缺失节点，必须用「下一层链表」逐个孩子追加。

❗ 用 leftmost.left 找下一层起点：稀疏树下一层最左节点不一定是当前层最左的左孩子（例：最左节点只有右子树）。

❗ 内层用 left/right 走当前层而非 next：会破坏 O(1) 层序思路；当前层应沿已填好的 next 横向扫描。

🔍 必测边界 Case

Case 1：空树
root = [] → []
Case 2：单节点
root = [1] → [1,#]
Case 3：官方示例 1（稀疏层）
root = [1,2,3,4,5,null,7] → 层 2: 2→3；层 3: 4→5→7
Case 4：仅右链
root = [1,null,2,null,3] → 每层只有一个节点，next 均为 NULL
Case 5：某层只有一个孩子
父节点只有 right 时，该孩子仍应正确接到同层 next 链末尾
