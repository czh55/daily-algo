#112 树前序递归 简单

📋 题目描述

给你二叉树的根节点 root 和一个表示目标和的整数 targetSum。判断该树中是否存在 根节点到叶子节点 的路径，这条路径上所有节点值相加等于 targetSum。若存在返回 true，否则 false。

叶子节点 是指没有子节点的节点。

树中节点数目 [0, 5000]，节点值与 targetSum 均在 [-1000, 1000] 范围内。

示例 1

输入：root = [5,4,8,11,null,13,4,7,2,null,null,null,1], targetSum = 22
输出：true
路径 5 → 4 → 11 → 2，节点值之和为 22。

示例 2

输入：root = [1,2,3], targetSum = 5
输出：false
根到叶路径和分别为 3 与 4，没有等于 5 的。

示例 3

输入：root = [], targetSum = 0
输出：false
空树不存在根到叶子的路径。

💭 模拟答题者思考

1. 暴力直觉：枚举每条根到叶的路径，把节点值加起来与 targetSum 比较——正确，但路径共享前缀会被重复遍历。

2. 重复在哪里？每往下走一层，都是在问「子树里有没有一条到叶的路径，其和等于已经扣掉祖先后的剩余目标」——子问题与整题同型。

3. 前序递推：到节点 u 时先把 rem -= u.val；若 u 是叶子且 rem == 0 则成功；否则向非空孩子继续传同一个 rem。

4. 易错点：在非叶子上看到 rem == 0 就返回 true（例如目标 0 但中间节点值为 0）——题目要求路径必须到叶子，中间不能停。

5. 每个节点访问常数次，时间 O(n)；递归栈 O(h)。

🧠 变量语义（先读这三句再编码）

变量类型语义（三句法）
remint定义：从当前节点走到某条叶子时，路径上尚未凑满的目标和（还差多少）
维护：进入节点前 rem 表示「含当前节点值后整条路径应等于原 target」的剩余量；在节点处先 rem -= node.val
更新：递归左/右孩子时传入同一 rem；在叶子处判定 rem == 0
nodeTreeNode*定义：DFS 当前访问的节点，从根沿一条路径向下
维护：只有左右皆空的节点才允许做「路径结束」判断；中间节点不能因 rem==0 提前返回 true
更新：先处理当前节点扣减 rem，再递归 left / right，用 or 合并是否存在合法路径
hasPathSum(root, targetSum)bool定义：以 root 为起点的子树中，是否存在根到叶路径和等于传入的 targetSum
维护：空节点无路径，恒 false；答案 = 左子树或右子树中任一侧为 true
更新：顶层调用 dfs(root, targetSum)，初始 rem 即为全局目标和

⌨️ 落码步骤

1. 若 root 为空，返回 false

2. 定义 dfs(node, rem)：rem -= node.val

3. 若 node 为叶子，返回 rem == 0

4. 否则返回 dfs(left, rem) or dfs(right, rem)（空孩子由 not node 分支处理为 false）

5. 对外接口：return dfs(root, targetSum)

💻 代码实现 

class Solution:
    def hasPathSum(self, root: TreeNode | None, targetSum: int) -> bool:
        def dfs(node: TreeNode | None, rem: int) -> bool:
            if not node:
                return False
            rem -= node.val
            if not node.left and not node.right:
                return rem == 0
            return dfs(node.left, rem) or dfs(node.right, rem)

        return dfs(root, targetSum)
class Solution {
public:
    bool hasPathSum(TreeNode* root, int targetSum) {
        return dfs(root, targetSum);
    }

private:
    bool dfs(TreeNode* node, int rem) {
        if (!node) return false;
        rem -= node->val;
        if (!node->left && !node->right)
            return rem == 0;
        return dfs(node->left, rem) || dfs(node->right, rem);
    }
};
// 时间 O(n)，空间 O(h)

📈 复杂度分析

时间复杂度 O(n)
空间复杂度 O(h)（递归栈深度，最坏 O(n)）

⚠️ 常见坑

❗ 未到叶子就判成功：在中间节点 rem == 0 也返回 true，违反「根到叶」定义。

❗ 把「空子树」当叶子：单节点树时根就是叶子；有孩子时即使一侧为空也不能在根处直接比较 targetSum == root.val。

❗ 先递归再扣减节点值：应在访问当前节点时更新 rem，否则叶子判定与路径前缀不一致。

🔍 必测边界 Case

Case 1：空树
root = [], targetSum = 0 → false
Case 2：单节点匹配
root = [1], targetSum = 1 → true
Case 3：单节点不匹配
root = [1], targetSum = 0 → false
Case 4：官方示例 1
root = [5,4,8,11,null,13,4,7,2,null,null,null,1], targetSum = 22 → true
Case 5：官方示例 2
root = [1,2,3], targetSum = 5 → false
