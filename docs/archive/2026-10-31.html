📋 题目描述

给你两个字符串 s 和 t，统计并返回在 s 的 子序列 中 t 出现的个数。

测试用例保证结果在 32 位有符号整数范围内。

1 ≤ s.length, t.length ≤ 1000，s 和 t 由英文字母组成。

示例 1

输入：s = "rabbbit", t = "rabbit"
输出：3
三种方案：rabbbit、rabbbit、rabbbit（下划线为选中的子序列字符）。

示例 2

输入：s = "babgbag", t = "bag"
输出：5

💭 模拟答题者思考

1. 暴力：从 s 里递归选/不选每一位，拼出与 t 相同的子序列并计数——正确，但 2^m 量级，长度上千必超时。

2. 重复在哪里？进度只取决于「已扫过 s 前几个字符、已匹配 t 前几个字符」，与具体选了哪些下标无关；同一对 (i,j) 会被大量路径重复访问。

3. 子问题：设 dp[i][j] 为 s[0..i-1] 中子序列等于 t[0..j-1] 的方案数。扫到 s[i-1] 时：若与 t[j-1] 不同，只能跳过 → dp[i][j]=dp[i-1][j]；若相同，可跳过（dp[i-1][j]）或用这一对配对（dp[i-1][j-1]），相加。

4. 手推示例 1 一角：s="rabbbit"、t="rabbit"。多出来的 b 会在「跳过 / 选用」之间产生分叉；三个 b 中选两个的不同组合正是额外计数来源，DP 的「加 dp[i-1][j-1]」就是在累加「在这里结束 t 的某一前缀」的路径数。

5. 边界：dp[i][0]=1（空 t 只有一种取法）；dp[0][j>0]=0。与 LCS/编辑距离同属双串二维 DP，但本题是计数而非最值，相等字符时是加法不是 max。

🧠 变量语义（先读这三句再编码）

变量类型语义（三句法）
dp[i][j]int[][]定义：s 的前 i 个字符里，能选出多少种不同下标的子序列，使其恰好等于 t 的前 j 个字符
维护：只依赖更短前缀 dp[i-1][·]；当 s[i-1]==t[j-1] 时可「用这一位配对 t[j-1]」或「跳过 s[i-1]」
更新：字符相等时 dp[i][j]=dp[i-1][j-1]+dp[i-1][j]；不等时 dp[i][j]=dp[i-1][j]；答案 dp[m][n]
i, jint定义：已考虑的 s 前缀长度、已匹配的 t 前缀长度，范围 0..m、0..n
维护：j=0 表示 t 为空串，任意 s 前缀都有且仅有 1 种取法（全不选）
更新：双重循环 i=1..m、j=1..n；dp[0][j>0]=0
m, nint定义：len(s)、len(t)
维护：若 m<n 则答案必为 0（t 比 s 长无法完全匹配）
更新：只读；结果在 32 位整数内

⌨️ 落码步骤

1. m,n = len(s), len(t)；建 (m+1)×(n+1) 整型表

2. 初始化 dp[i][0]=1（i=0..m），dp[0][j]=0（j=1..n）

3. 对 i=1..m、j=1..n：若 s[i-1]==t[j-1]，dp[i][j]=dp[i-1][j-1]+dp[i-1][j]

4. 否则 dp[i][j]=dp[i-1][j]

5. 返回 dp[m][n]（注意用 64 位累加再转 int，防中间溢出）

💻 代码实现 

class Solution:
    def numDistinct(self, s: str, t: str) -> int:
        m, n = len(s), len(t)
        dp = [[0] * (n + 1) for _ in range(m + 1)]
        for i in range(m + 1):
            dp[i][0] = 1  # 空 t：一种取法（全不选）
        for i in range(1, m + 1):
            for j in range(1, n + 1):
                if s[i - 1] == t[j - 1]:
                    dp[i][j] = dp[i - 1][j - 1] + dp[i - 1][j]
                else:
                    dp[i][j] = dp[i - 1][j]
        return dp[m][n]
class Solution {
public:
    int numDistinct(string s, string t) {
        int m = s.size(), n = t.size();
        vector<vector<long long>> dp(m + 1, vector<long long>(n + 1, 0));
        for (int i = 0; i <= m; ++i) dp[i][0] = 1;
        for (int i = 1; i <= m; ++i) {
            for (int j = 1; j <= n; ++j) {
                if (s[i - 1] == t[j - 1])
                    dp[i][j] = dp[i - 1][j - 1] + dp[i - 1][j];
                else
                    dp[i][j] = dp[i - 1][j];
            }
        }
        return (int)dp[m][n];
    }
};
// 时间 O(mn)，空间 O(mn)；可压成 O(n) 滚动

📈 复杂度分析

时间复杂度 O(m × n)（m=len(s)，n=len(t)）
空间复杂度 O(m × n)（二维 dp；可滚动为一维 O(n)）

⚠️ 常见坑

❗ 字符相等时写成 dp[i][j]=dp[i-1][j-1] 漏掉「跳过当前 s[i-1]」的 dp[i-1][j]，示例 1 会少计多 b 的分支。

❗ 边界搞反：dp[0][j]=0（j>0）、dp[i][0]=1；把第一行也设成 1 或把第一列当 0 都会错。

❗ 与「最长公共子序列」混淆：LCS 求长度用 max；本题求方案个数，匹配字符时是相加两种决策的路径数。

🔍 必测边界 Case

Case 1：t 为空
s 任意非空 → 1（只选空子序列一种）
Case 2：s 比 t 短
s="ab", t="abc" → 0
Case 3：完全相同
s="abc", t="abc" → 1
Case 4：重复字符分叉
s="aaa", t="a" → 3（三个 a 各可选一次）
Case 5：官方示例 2
s="babgbag", t="bag" → 5
