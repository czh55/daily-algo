#122 贪心 中等

买卖股票的最佳时机 II

📋 题目描述

给你一个整数数组 prices，其中 prices[i] 表示某支股票第 i 天的价格。

在每一天，你可以决定是否购买和/或出售股票。你在任何时候 最多 只能持有 一股 股票。然而，你可以在 同一天 多次买卖该股票，但要确保你持有的股票不超过一股。

返回你能获得的 最大 利润。

示例 1

输入：prices = [7,1,5,3,6,4]
输出：7
第 2 天（价 1）买、第 3 天（价 5）卖，利润 4；第 4 天（价 3）买、第 5 天（价 6）卖，利润 3；合计 7。

示例 2

输入：prices = [1,2,3,4,5]
输出：4
第 1 天买入、第 5 天卖出，利润 5-1=4。

示例 3

输入：prices = [7,6,4,3,1]
输出：0
全程下跌，不参与交易最优，利润为 0。

💭 模拟答题者思考

1. 暴力：枚举起买、止卖日组合（多笔、不重叠且先买后卖），状态空间巨大，O(2ⁿ) 级，不可行。

2. 重复在哪里？任意一笔跨多天的盈利 prices[sell] - prices[buy]，可拆成连续若干天「昨日买、今日卖」的价差之和，且只有上涨日贡献正利润。

3. 贪心关键：最大化总利润 ⇔ 把所有相邻上涨的价差全部收入囊中——下跌日不买不卖，等价于跳过负贡献。

4. 与 #121 对比：#121 至多一笔；本题可多次交易，但「同一天先卖后买」允许，故每一段上涨都能独立结算，一次扫描累加即可。

5. 等价 DP 视角：hold / cash 两状态转移也能 O(n)，但贪心累加相邻正差更短、更直观。

🧠 变量语义（先读这三句再编码）

变量类型语义（三句法）
ansint定义：在允许多笔交易、同时最多持有 1 股的前提下，累计可获得的最大利润
维护：初值 0；只累加「正利润」的价差片段
更新：相邻两天价差为正时 ans += prices[i] - prices[i-1]（等价于吃掉每一段上涨）
prices[i]int定义：第 i 天的股价，与前一天比较刻画「本日相对昨日的涨跌」
维护：从左到右扫描，仅需相邻两天 (i-1, i)
更新：当 prices[i] > prices[i-1] 时，认为在昨日买、今日卖能无风险地赚到这段涨幅
diffint定义：单日边际利润 diff = prices[i] - prices[i-1]
维护：每步只依赖当前与前一价格，不需显式记录持仓
更新：if diff > 0: ans += diff；下跌或持平则 diff ≤ 0 不累加

⌨️ 落码步骤

1. 初始化 ans = 0

2. 从下标 1 遍历到 n-1

3. 计算 diff = prices[i] - prices[i-1]

4. 若 diff > 0，则 ans += diff

5. 返回 ans

💻 代码实现 

class Solution:
    def maxProfit(self, prices: list[int]) -> int:
        ans = 0
        for i in range(1, len(prices)):
            diff = prices[i] - prices[i - 1]
            if diff > 0:
                ans += diff
        return ans
class Solution {
public:
    int maxProfit(vector<int>& prices) {
        int ans = 0;
        for (int i = 1; i < (int)prices.size(); i++) {
            int diff = prices[i] - prices[i - 1];
            if (diff > 0) {
                ans += diff;
            }
        }
        return ans;
    }
};
// 时间 O(n)，空间 O(1)

⚠️ 常见坑

❗ 勿与 #121 混淆：本题可多笔交易，不能只用「全局最低买一次」；要把每段上涨都算上。

❗ 只有 diff > 0 才累加；持平或下跌不加，否则会做出「高买低卖」的负利润。

❗ 循环从 i=1 开始：单元素数组无相邻日，应直接返回 0。

🔍 必测边界 Case

Case 1：单天
prices = [3] → 0（无法完成买卖）
Case 2：单调上涨
prices = [1,2,3,4,5] → 4（等价于 1 买 5 卖，或逐日吃差）
Case 3：单调下跌
prices = [7,6,4,3,1] → 0
Case 4：震荡上升
prices = [7,1,5,3,6,4] → 7（多段上涨：1→5、3→6）
Case 5：相邻持平
prices = [2,2,3] → 1（0 差不累加，仅 2→3 贡献 1）
