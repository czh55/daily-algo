最长连续序列

📋 题目描述

给定一个未排序的整数数组 nums，找出数字连续的最长序列（不要求序列元素在原数组中连续）的长度。

请你设计并实现时间复杂度为 O(n) 的算法解决此问题。

示例 1

输入：nums = [100,4,200,1,3,2]
输出：4
最长数字连续序列是 [1, 2, 3, 4]。它的长度为 4。

示例 2

输入：nums = [0,3,7,2,5,8,4,6,0,1]
输出：9
连续段为 0,1,2,…,8，长度为 9（重复出现的 0 只计一次）。

示例 3

输入：nums = [1,0,1,2]
输出：3
最长连续序列是 [0, 1, 2]。

💭 模拟答题者思考

1. 暴力：先排序，再线性扫相邻差为 1 的段——时间 O(n log n)，不满足 O(n)；且题面强调元素不必在原数组中连续，讲的是数值上的连续。

2. 重复在哪里？若从每个数都向右数 +1、+2…，同一段会被多个起点重复扩展；例如段 [1,2,3,4] 会从 1、2、3、4 各扫一遍，浪费成 O(n²)。

3. 关键：只有连续段的最小值才值得当起点——若 num-1 也在集合里，说明 num 不是段首，直接跳过。

4. 用哈希集合存全部数；对每个「段首」num（满足 num-1 ∉ st）不断查 num+1, num+2, … 是否在 st，算出段长并更新答案。

5. 均摊 O(n)：每个数最多作为段首扩展一次、作为中间元素最多被经过一次，总操作线性；并查集写法亦可行，但「只从段首扩展」更直观。

🧠 变量语义（先读这三句再编码）

变量类型语义（三句法）
stset<int>定义：数组中所有出现过的整数集合（去重），用于 O(1) 判断某值是否存在
维护：建好后不变，扩展连续段时只读 st
更新：st = set(nums)
numint定义：当前考察的数组元素值（可遍历 st 或 nums）
维护：仅当 num - 1 ∉ st 时，把 num 当作某条连续段的起点再向右扩展
更新：每轮取下一个 num，非起点则跳过，避免同一段重复计数
cur / nxtint定义：从起点 num 开始，当前段已确认的最右端值；扩展时看 nxt = cur + 1 是否在 st 中
维护：段长为「从起点连续 +1 能走多远」的整数个数
更新：while nxt in st: cur = nxt; nxt += 1，段长 = cur - num + 1
ansint定义：目前为止见过的最长连续段长度
维护：每完成一次从合法起点出发的扩展后更新
更新：ans = max(ans, cur - num + 1)

⌨️ 落码步骤

1. st = set(nums)；若为空返回 0

2. ans = 0；遍历 num in st（或 nums）

3. 若 num - 1 in st，跳过（非连续段起点）

4. 令 cur = num，当 cur + 1 in st 时 cur += 1

5. ans = max(ans, cur - num + 1)；遍历结束返回 ans

💻 代码实现 

class Solution:
    def longestConsecutive(self, nums: list[int]) -> int:
        st = set(nums)
        if not st:
            return 0
        ans = 0
        for num in st:
            if num - 1 in st:
                continue
            cur = num
            while cur + 1 in st:
                cur += 1
            ans = max(ans, cur - num + 1)
        return ans
class Solution {
public:
    int longestConsecutive(vector<int>& nums) {
        unordered_set<int> st(nums.begin(), nums.end());
        if (st.empty()) return 0;
        int ans = 0;
        for (int num : st) {
            if (st.count(num - 1)) continue;
            int cur = num;
            while (st.count(cur + 1)) ++cur;
            ans = max(ans, cur - num + 1);
        }
        return ans;
    }
};
// 时间 O(n)，空间 O(n)

⚠️ 常见坑

❗ 未判断段首就做扩展：从每个数都向右扫会导致同一段被重复计算，最坏 O(n²)。必须先确认 num-1 不在集合中。

❗ 排序后扫「数组下标相邻」：连续指数组里缺数字也算一段（如 [1,3,5] 最长为 1），不能把下标连续当成数值连续。

❗ 重复元素：应用集合去重；多个相同值不改变最长连续段长度，但不能因此漏掉段首判断。

🔍 必测边界 Case

Case 1：空数组
nums = [] → 0
Case 2：单元素
nums = [7] → 1
Case 3：全无连续
nums = [100, 4, 200, 1, 3, 2] 中孤立大数 → 同时存在长度 4 的段
Case 4：含重复值
nums = [0,3,7,2,5,8,4,6,0,1] → 9
Case 5：负数与跨零连续
nums = [-1, 0, 1, 2] → 4
