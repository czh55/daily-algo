📋 题目描述

给定一个非负整数 numRows，生成「杨辉三角」的前 numRows 行。

在「杨辉三角」中，每个数是它左上方和右上方的数的和；每行首尾元素均为 1。

1 ≤ numRows ≤ 30。

示例 1

输入：numRows = 5
输出：[[1],[1,1],[1,2,1],[1,3,3,1],[1,4,6,4,1]]

示例 2

输入：numRows = 1
输出：[[1]]

💭 模拟答题者思考

1. 暴力直觉：按定义对每个位置递归求「左上方 + 右上方」，边界返回 1——正确但大量重复计算，复杂度指数级。

2. 重复在哪里？第 r 行的每个数只依赖第 r-1 行相邻两个数，同一上一行元素被多次相加，应按行自底向上填表，不要对每个格子单独递归。

3. 递推：第 0 行 [1]；第 r 行（r≥1）长度为 r+1，row[0]=row[r]=1，且 row[j] = prev[j-1] + prev[j]（1≤j≤r-1）。手推 numRows=5 可得官方输出。

4. 外层循环行号、内层填中间位即可；共 1+2+…+numRows 个元素，时间 O(numRows²)，空间主要由输出矩阵决定。

🧠 变量语义（先读这三句再编码）

变量类型语义（三句法）
trianglelist[list[int]]定义：已生成的杨辉三角，triangle[r] 为第 r 行（0 起）
维护：每轮外层循环结束，triangle 多一行且该行满足递推关系
更新：构造完 row 后 triangle.append(row)
rowlist[int]定义：当前正在构造的第 r 行，长度为 r+1
维护：row[0] 与 row[r] 恒为 1；中间位由上一行相邻两数相加
更新：每新一层重置为 [1]，再逐位填中间，最后补末尾 1（或先定两端再填中间）
prevlist[int]定义：上一行 triangle[r-1]，长度 r
维护：仅在本层构造中间元素时使用
更新：每轮 prev = triangle[-1]（或直接用 triangle[r-1]）

⌨️ 落码步骤

1. 若 numRows == 0（本题约束下不会出现）返回空；否则初始化 triangle = [[1]]

2. 对 r = 1 .. numRows-1 构造新行：row = [1]

3. 令 prev = triangle[r-1]，对 j = 1 .. r-1 执行 row.append(prev[j-1] + prev[j])

4. 行末再 row.append(1)，将 row 加入 triangle

5. 返回 triangle

💻 代码实现 

class Solution:
    def generate(self, numRows: int) -> list[list[int]]:
        if numRows == 0:
            return []
        triangle = [[1]]
        for r in range(1, numRows):
            prev = triangle[r - 1]
            row = [1]
            for j in range(1, r):
                row.append(prev[j - 1] + prev[j])
            row.append(1)
            triangle.append(row)
        return triangle
class Solution {
public:
    vector<vector<int>> generate(int numRows) {
        vector<vector<int>> triangle;
        if (numRows == 0) return triangle;
        triangle.push_back({1});
        for (int r = 1; r < numRows; ++r) {
            const vector<int>& prev = triangle[r - 1];
            vector<int> row = {1};
            for (int j = 1; j < r; ++j)
                row.push_back(prev[j - 1] + prev[j]);
            row.push_back(1);
            triangle.push_back(move(row));
        }
        return triangle;
    }
};
// 时间 O(numRows²)，空间 O(numRows²)

📈 复杂度分析

时间复杂度 O(numRows²)
空间复杂度 O(numRows²)（输出占主导；若只存上一行可 O(numRows)）

⚠️ 常见坑

❗ 内层下标越界：中间位只用 j ∈ [1, r-1]，对应 prev[j-1]+prev[j]；若写成 j ∈ [0, r) 会在 j=0 访问 prev[-1] 语义错误或越界。

❗ 忘记每行两端为 1：只递推中间会把首尾当成 0 或漏填，输出行长度不对。

❗ 行数 off-by-one：应生成恰好 numRows 行（第 0 行算一行）；循环 r < numRows 且已有首行，或 range(numRows) 内区分首行，避免多一行或少一行。

🔍 必测边界 Case

Case 1：一行
numRows = 1 → [[1]]
Case 2：两行
numRows = 2 → [[1],[1,1]]
Case 3：官方示例 1
numRows = 5 → 第五行 [1,4,6,4,1]
Case 4：最大规模
numRows = 30 → 第 30 行 30 个元素，中间位由第 29 行递推，无溢出（值在 int 范围内）
