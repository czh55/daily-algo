📋 题目描述

给你一个链表的头节点 head，判断链表中是否有环。

如果链表中有某个节点，可以通过连续跟踪 next 指针再次到达，则链表中存在环。评测系统用整数 pos 表示尾结点连回的位置（索引从 0 开始），pos 不作为参数传入，仅用于构造测试数据。

有环返回 true，否则返回 false。

0 <= 节点数 <= 104，-105 <= Node.val <= 105，pos 为 -1 或有效索引。

示例 1

输入：head = [3,2,0,-4], pos = 1
输出：true
尾部连接到第二个节点，形成环。

示例 2

输入：head = [1,2], pos = 0
输出：true
尾部连接到第一个节点。

示例 3

输入：head = [1], pos = -1
输出：false
单节点且 next 为空，无环。

💭 模拟答题者思考

1. 暴力：用哈希集合记录「已访问节点」，若下一步落在集合里则有环——时间 O(n)、空间 O(n)，符合题意但进阶要求 O(1) 额外空间。

2. 重复在哪里？无环链表的节点只会被走一次；有环时从某点起会在环里无限转圈，本质是「是否再次经过同一节点」。

3. Floyd 判圈：快指针每次走 2 步、慢指针走 1 步。无环时快指针先碰到 null；有环时二者进入环后，快指针像绕操场追人，相对速度为 1，必在某处相遇。

4. 落码只需在相遇时返回 true；若 fast 走到尽头（或 fast.next 为空）则返回 false。

🧠 变量语义（先读这三句再编码）

变量类型语义（三句法）
slowListNode*定义：慢指针，每轮沿 next 走 1 步
维护：与 fast 同从 head 出发；若有环，二者终将在环内某点相遇
更新：每轮 slow = slow.next
fastListNode*定义：快指针，每轮沿 next 走 2 步
维护：无环时先到尽头；有环时在环内追上慢指针
更新：每轮 fast = fast.next.next，且进入循环前需保证 fast 与 fast.next 非空

⌨️ 落码步骤

1. 若 head is None 或 head.next is None，直接 return False

2. slow = fast = head

3. 循环条件 while fast and fast.next：先推进 slow = slow.next，fast = fast.next.next

4. 若 slow == fast，返回 True

5. 循环正常结束返回 False

💻 代码实现 

class Solution:
    def hasCycle(self, head: Optional[ListNode]) -> bool:
        if not head or not head.next:
            return False
        slow = fast = head
        while fast and fast.next:
            slow = slow.next
            fast = fast.next.next
            if slow is fast:
                return True
        return False
class Solution {
public:
    bool hasCycle(ListNode *head) {
        if (!head || !head->next) return false;
        ListNode* slow = head;
        ListNode* fast = head;
        while (fast && fast->next) {
            slow = slow->next;
            fast = fast->next->next;
            if (slow == fast) return true;
        }
        return false;
    }
};
// 时间 O(n)，空间 O(1)

📈 复杂度分析

时间复杂度 O(n)
空间复杂度 O(1)（快慢指针；哈希表写法为 O(n)）

⚠️ 常见坑

❗ 循环写成 while fast 却不判 fast.next：快指针要走两步，在最后一个节点上对空指针取 next 会崩溃——应写 while (fast && fast->next)。

❗ 在移动指针之前就判断 slow == fast：初态二者同为 head 会误判有环；应先各走一轮再比较，或在循环内先移动再判相等。

❗ 误以为只有尾连回头才有环：环可在任意位置闭合；判环不依赖 pos，只关心指针是否重复经过同一节点。

🔍 必测边界 Case

Case 1：空链表
head = null → false
Case 2：单节点无环
[1], pos = -1 → false（官方示例 3）
Case 3：两节点成环
[1,2], pos = 0 → true（官方示例 2）
Case 4：长链尾入环
[3,2,0,-4], pos = 1 → true（官方示例 1）
