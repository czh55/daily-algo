📋 题目描述

给你无向连通图中一个节点的引用，请你返回该图的深拷贝（克隆）。

图中的每个节点都包含它的值 val（int）和其邻居的列表（list[Node]）。

class Node {
    public int val;
    public List<Node> neighbors;
}

简单起见，每个节点的值都和它的索引相同。给定节点将始终是图中的第一个节点（值为 1）。你必须将给定节点的拷贝作为对克隆图的引用返回。

图中节点数 [0, 100]；节点值唯一；无重复边、无自环；图为连通图。

示例 1

输入：adjList = [[2,4],[1,3],[2,4],[1,3]]
输出：[[2,4],[1,3],[2,4],[1,3]]
4 个节点：1 邻接 2、4；2 邻接 1、3；3 邻接 2、4；4 邻接 1、3。克隆后结构相同，但各 Node 对象均为新分配。

示例 2

输入：adjList = [[]]
输出：[[]]
只有一个值为 1 的节点，无任何邻居。

示例 3

输入：adjList = []
输出：[]
图为空，不含任何节点，应返回 null。

💭 模拟答题者思考

1. 暴力：深拷贝整个邻接表结构——但对每个节点「new 一个副本」时，邻居指针仍指向原图 或错误重复 new，同一拓扑在不同边上会对应多个互不关联的克隆，判题会失败。

2. 重复在哪里？无向连通图中，节点值唯一，「原节点 identity」与「克隆节点」必须一对一；每条边 (u,v) 在克隆图上要连的是 (clone(u), clone(v))，而 clone(u) 依赖 u 是否已建过。

3. 核心：哈希表 原 → 克隆。走到原节点 u 时，若表中没有就先创建 clone(u)；接着把每个邻居 v 的 clone(v) 挂到 clone(u).neighbors——若 v 尚未克隆则递归/BFS 继续。

4. 用 BFS：从给定节点入队，出队时补全邻居边并扩展新顶点，与 #127 单词接龙同属「图上层次扩展」，但边来自显式邻接表、且需维护克隆映射。

5. node is null（空图）直接返回 null；单点无邻居时映射里只有起点、邻居列表为空。整张图每个点与每条边各访问常数次，O(V+E)。

🧠 变量语义（先读这三句再编码）

变量类型语义（三句法）
mpdict / map<Node*,Node*>定义：原图节点 → 已创建克隆节点的映射，保证同一原节点只克隆一次、邻居可复用同一克隆体
维护：首次从 BFS 到达某原节点时立刻为其 new Node(val) 并登记；后续仅通过 mp 取克隆指针挂边
更新：起点入队前先 mp[node]=Node(node.val)；发现邻居 v 未在表中则新建并入队
qdeque定义：待处理「原图节点」的 BFS 队列，保证按连通块顺序扩展克隆体的邻居表
维护：队头出队后对每个原邻居补全 mp[cur].neighbors 并可能让新原节点入队
更新：初始入队给定 node；仅当 v ∉ mp 时把 v 入队
curNode*（原）定义：本轮正在为其克隆体 mp[cur] 连接全部无向边的原图节点
维护：遍历 cur.neighbors，将 mp[nb] 追加进克隆邻接表（无向图每条边处理一次即可方向一致）
更新：每次 q.popleft() 得到

⌨️ 落码步骤

1. 若 node is None，返回 None

2. 创建空映射 mp，mp[node] = Node(node.val)，队列入 node

3. BFS：出队 cur，遍历 cur.neighbors 中每个 nb

4. 若 nb ∉ mp，则 mp[nb]=Node(nb.val) 并将 nb 入队

5. 将 mp[nb] 追加到 mp[cur].neighbors

6. 返回 mp[node]（给定节点的克隆根）

💻 代码实现 

from collections import deque
from typing import Optional

# class Node:
#     def __init__(self, val=0, neighbors=None):
#         self.val = val
#         self.neighbors = neighbors if neighbors is not None else []

class Solution:
    def cloneGraph(self, node: Optional['Node']) -> Optional['Node']:
        if node is None:
            return None
        mp = {node: Node(node.val)}
        q = deque([node])
        while q:
            cur = q.popleft()
            clone = mp[cur]
            for nb in cur.neighbors:
                if nb not in mp:
                    mp[nb] = Node(nb.val)
                    q.append(nb)
                clone.neighbors.append(mp[nb])
        return mp[node]
/*
// Definition for a Node.
class Node {
public:
    int val;
    vector<Node*> neighbors;
    Node() { val = 0; neighbors = {}; }
    Node(int _val) { val = _val; neighbors = {}; }
};
*/

class Solution {
public:
    Node* cloneGraph(Node* node) {
        if (!node) return nullptr;
        unordered_map<Node*, Node*> mp;
        queue<Node*> q;
        mp[node] = new Node(node->val);
        q.push(node);
        while (!q.empty()) {
            Node* cur = q.front();
            q.pop();
            for (Node* nb : cur->neighbors) {
                if (!mp.count(nb)) {
                    mp[nb] = new Node(nb->val);
                    q.push(nb);
                }
                mp[cur]->neighbors.push_back(mp[nb]);
            }
        }
        return mp[node];
    }
};
// 时间 O(V+E)，空间 O(V)

⚠️ 常见坑

❗ 不做映射、对每个邻居直接 new Node(nb.val) 再递归：同一 nb 被多条边引用时会生成多个克隆，图结构错误且可能无限递归。

❗ 忘记 adjList = [] 时入参为 null，须先判空再访问 node.val / 入队。

❗ DFS 写法若在「挂邻居」之后才登记映射，从 u 到 v 再到 u 可能重复创建；应在进入/发现节点时立刻写入 mp。

🔍 必测边界 Case

Case 1：空图
node = null → null
Case 2：孤立单点
adjList = [[]] → 一个克隆节点、neighbors 为空
Case 3：两节点互连
[[2],[1]]：clone(1) 与 clone(2) 互相指向，而非指向原图 1、2
Case 4：较大连通图
节点 ≤ 100、值唯一，验证映射大小等于 V、边数 2E 次 append
