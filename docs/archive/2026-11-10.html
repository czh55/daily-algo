📋 题目描述

如果在将所有大写字符转换为小写字符、并移除所有非字母和非数字字符之后，短语正着读和反着读都一样。则可以认为该短语是一个 回文串 。

字母和数字都属于字母数字字符。

给你一个字符串 s，如果它是 回文串 ，返回 true ；否则，返回 false 。

示例 1

输入：s = "A man, a plan, a canal: Panama"
输出：true
"amanaplanacanalpanama" 是回文串。

示例 2

输入：s = "race a car"
输出：false
"raceacar" 不是回文串。

示例 3

输入：s = " "
输出：true
移除非字母数字字符之后为空串，空串视为回文。

💭 模拟答题者思考

1. 我先按题意预处理：过滤出所有字母数字、转小写得到字符串 t，再判断 t == t[::-1]——正确，但要额外 O(n) 空间存 t，长度可达 2×10⁵。

2. 重复在哪里？回文只要求「对称位置上的有效字符」相等，标点与空格从不参与比较，不必真的删掉它们。

3. 双指针：两端向中间走，各指针先向内跳过非字母数字，再比较小写后的字符；全部配对成功即为回文。

4. 为什么跳过合法？当 l 还在 r 左侧时，被跳过的字符在回文意义上没有「对称搭档」，不影响已配对部分的正确性。

5. 空有效串（如示例 3）：指针相遇或交叉前未出现不等比较，循环正常结束，返回 true。时间 O(n)（每字符最多被两个指针各访问一次），空间 O(1)。

🧠 变量语义（先读这三句再编码）

变量类型语义（三句法）
lint定义：从左侧找到的、下一个待参与比较的字母数字字符下标
维护：初始 0；若当前字符非字母数字则右移，直到 s[l] 有效或 l >= r
更新：一轮比较成功后 l += 1
rint定义：从右侧找到的、下一个待参与比较的字母数字字符下标
维护：初始 len(s) - 1；跳过非字母数字则左移
更新：比较成功后 r -= 1
norm(c)char定义：将字母数字字符统一为小写（或等价比较）后的规范形式
维护：只对 isalnum 为真的字符调用
更新：每对 (l, r) 比较 norm(s[l]) 与 norm(s[r])，不等则立刻返回 false

⌨️ 落码步骤

1. 令 l = 0，r = len(s) - 1

2. 当 l < r：内层循环使 s[l] 为字母数字，否则 l++；同理调整 r

3. 若仍 l < r 且 tolower(s[l]) != tolower(s[r])，返回 false

4. 否则 l++、r--，继续下一对

5. 循环结束返回 true

💻 代码实现 

class Solution:
    def isPalindrome(self, s: str) -> bool:
        l, r = 0, len(s) - 1

        def alnum(i: int) -> bool:
            return s[i].isalnum()

        while l < r:
            while l < r and not alnum(l):
                l += 1
            while l < r and not alnum(r):
                r -= 1
            if s[l].lower() != s[r].lower():
                return False
            l += 1
            r -= 1
        return True
class Solution {
public:
    bool isPalindrome(string s) {
        int l = 0, r = (int)s.size() - 1;
        while (l < r) {
            while (l < r && !isalnum(s[l])) ++l;
            while (l < r && !isalnum(s[r])) --r;
            if (tolower(s[l]) != tolower(s[r]))
                return false;
            ++l;
            --r;
        }
        return true;
    }
};
// 时间 O(n)，空间 O(1)

⚠️ 常见坑

❗ 大小写：必须统一成小写（或 tolower）再比较，'A' != 'a' 若不做规范化会误判。

❗ 跳过非法字符时也要检查 l < r，否则指针交叉后仍访问会越界或重复比较。

❗ 数字参与回文：'0'、'1' 等算字母数字字符，isalnum 为真；勿只处理字母。

🔍 必测边界 Case

Case 1：仅标点/空格
s = " " 或 ",.!" → true（有效字符为空）
Case 2：单字符
s = "a" → true；s = "0" → true
Case 3：大小写混合
s = "Aa" → true
Case 4：首尾不对称
s = "race a car" → false
Case 5：数字回文
s = "0P" → false（'0' vs 'P'）
