#138 哈希表 中等

随机链表的复制

📋 题目描述

给你一个长度为 n 的链表，每个节点包含一个额外增加的随机指针 random，该指针可以指向链表中的任何节点或空节点。

构造这个链表的深拷贝：复制链表应由 n 个全新节点组成，每个新节点的值等于对应原节点，且 next、random 都指向复制链表中的新节点。复制链表中的指针均不得指向原链表中的节点。

0 <= n <= 1000，-104 <= Node.val <= 104，Node.random 为 null 或指向链表中的节点。

示例 1

输入：head = [[7,null],[13,0],[11,4],[10,2],[1,0]]
输出：[[7,null],[13,0],[11,4],[10,2],[1,0]]

示例 2

输入：head = [[1,1],[2,1]]
输出：[[1,1],[2,1]]

示例 3

输入：head = [[3,null],[3,0],[3,null]]
输出：[[3,null],[3,0],[3,null]]

💭 模拟答题者思考

1. 暴力直觉：按顺序复制每个节点的 val，再按索引数组还原 next 与 random——可行但丢失链表结构，且 random 是指针不是下标时不好处理。

2. 重复在哪里？设 random 指针时，若只知道「原 random 指向谁」，却找不到「新链表里对应的那一个」，就会误指到原节点或重复造节点。

3. 核心转化：深拷贝的关键不是「复制值」，而是建立原节点 → 新节点的一一对应；有了这张表，new.random = old_to_new[old.random] 就能 O(1) 翻译任意 random 关系。

4. 故拆两轮：第一轮只造节点并登记映射；第二轮遍历原链表，用表给每个新节点接上正确的 next 与 random。

5. 进阶：可用「穿插复制 + 拆链」做到 O(1) 额外空间，但哈希表两遍写法最不易写错，适合作为变量语义法的标准落码。

🧠 变量语义（先读这三句再编码）

变量类型语义（三句法）
old_to_newdict[Node→Node]定义：原节点到新节点的映射表
维护：第一轮遍历后，表中每个原节点都有唯一对应的新节点
更新：扫过原节点 cur 时 old_to_new[cur] = Node(cur.val)
curNode*定义：当前正在处理的原链表节点
维护：第一轮建表、第二轮连线时沿 next 从左到右推进
更新：每轮 cur = cur.next
newHeadNode*定义：复制链表的头节点
维护：等于 old_to_new[head]（若 head 非空）
更新：第一轮建表完成后一次性确定，之后只改各节点的 next/random

⌨️ 落码步骤

1. 若 head is None，直接返回 None

2. 第一轮：cur = head，沿 next 遍历，对每个 cur 执行 old_to_new[cur] = Node(cur.val)

3. 第二轮：cur = head 再扫一遍，令 old_to_new[cur].next = old_to_new.get(cur.next)（cur.next 为空则 get 得 None）

4. 同步设置 old_to_new[cur].random = old_to_new.get(cur.random)

5. 返回 old_to_new[head]

💻 代码实现 

class Solution:
    def copyRandomList(self, head: 'Optional[Node]') -> 'Optional[Node]':
        if not head:
            return None
        old_to_new = {}  # 原节点 -> 复制节点
        cur = head
        while cur:
            old_to_new[cur] = Node(cur.val)
            cur = cur.next
        cur = head
        while cur:
            old_to_new[cur].next = old_to_new.get(cur.next)
            old_to_new[cur].random = old_to_new.get(cur.random)
            cur = cur.next
        return old_to_new[head]
class Solution {
public:
    Node* copyRandomList(Node* head) {
        if (!head) return nullptr;
        unordered_map<Node*, Node*> old_to_new;
        for (Node* cur = head; cur; cur = cur->next)
            old_to_new[cur] = new Node(cur->val);
        for (Node* cur = head; cur; cur = cur->next) {
            if (cur->next)
                old_to_new[cur]->next = old_to_new[cur->next];
            else
                old_to_new[cur]->next = nullptr;
            if (cur->random)
                old_to_new[cur]->random = old_to_new[cur->random];
            else
                old_to_new[cur]->random = nullptr;
        }
        return old_to_new[head];
    }
};
// 时间 O(n)，空间 O(n)

⚠️ 常见坑

❗ 在一轮循环里同时建节点又接 next：cur.next 对应的新节点可能尚未创建，访问 old_to_new[cur.next] 会 KeyError——必须先全部建档、再统一连线。

❗ 直接把 new.random = old.random：违反题意，新节点仍指向原链表；必须用 old_to_new[old.random] 翻译。

❗ 用 old_to_new[cur.next] 而非 .get(...)：尾节点或 random is null 时应对应 None，不能强取字典键。

🔍 必测边界 Case

Case 1：空链表
head = null → null
Case 2：单节点 random 为空
[[7,null]] → [[7,null]]
Case 3：random 指回自己
[[1,1],[2,1]] → 第二个节点的 random 指向第一个复制节点
Case 4：多个节点 val 相同
[[3,null],[3,0],[3,null]] → 映射按节点身份而非 val 区分
