📋 题目描述

给你二叉树的根节点 root 和一个整数目标和 targetSum，找出所有 从根节点到叶子节点 路径总和等于给定目标和的路径。

叶子节点 是指没有子节点的节点。

树中节点总数在范围 [0, 5000] 内，节点值与 targetSum 均在 [-1000, 1000] 范围内。

示例 1

输入：root = [5,4,8,11,null,13,4,7,2,null,null,5,1], targetSum = 22
输出：[[5,4,11,2],[5,8,4,5]]
两条根到叶路径和均为 22：5→4→11→2 与 5→8→4→5。

示例 2

输入：root = [1,2,3], targetSum = 5
输出：[]
根到叶路径和为 3 与 4，没有等于 5 的。

示例 3

输入：root = [1,2], targetSum = 0
输出：[]

💭 模拟答题者思考

1. 暴力直觉：枚举每条根到叶的路径，把节点值列出来并求和，等于 targetSum 就加入答案——与 #112 判断「是否存在」同型，只是要收集全部合法路径。

2. 重复在哪里？共享前缀的多条路径会在同一祖先上重复维护「当前路径序列」和「剩余目标和」——适合一条 DFS 上用公共 path，分叉时回溯撤销。

3. 前序 + 回溯：到节点 u 时 path.append(u.val)、rem -= u.val；若 u 是叶子且 rem==0 则 ans.append(path[:])；否则递归非空孩子；返回前 path.pop()。

4. 与 #112 的差异：不能一发现 rem==0 就停——必须到叶子；也不能只返回 bool，要在叶子层拷贝整条 path。

5. 每个节点进出各一次，时间 O(n)；输出路径总长最坏 O(n²)，递归栈 O(h)。

🧠 变量语义（先读这三句再编码）

变量类型语义（三句法）
pathlist<int>定义：从根到当前 DFS 节点的节点值序列（不含尚未访问的孩子）
维护：进入节点前 append(node.val)，离开该子树前 pop() 撤销
更新：前序「选当前点 → 递归孩子 → 撤销」；只在叶子且 rem==0 时把 path[:] 记入答案
remint定义：沿当前 path 走到叶子时，路径和还差多少才等于原 targetSum
维护：每进入节点 rem -= node.val；传给左右孩子的是扣减后的同一 rem
更新：与 #112 相同：仅叶子允许用 rem == 0 判定成功，中间节点不能提前收集
anslist<list<int>>定义：所有满足条件的根到叶路径集合
维护：DFS 过程中只追加完整路径的副本，不存前缀
更新：if 叶子 and rem==0: ans.append(path[:])

⌨️ 落码步骤

1. 若 root 为空，返回 []

2. 定义 dfs(node, rem, path)：空节点直接返回

3. path.append(node.val)，rem -= node.val

4. 若 node 为叶子且 rem == 0，ans.append(path[:])

5. 否则分别 dfs(left, rem, path)、dfs(right, rem, path)

6. 回溯：path.pop()；对外 dfs(root, targetSum, []) 后返回 ans

💻 代码实现 

class Solution:
    def pathSum(self, root: TreeNode | None, targetSum: int) -> list[list[int]]:
        ans: list[list[int]] = []

        def dfs(node: TreeNode | None, rem: int, path: list[int]) -> None:
            if not node:
                return
            path.append(node.val)
            rem -= node.val
            if not node.left and not node.right and rem == 0:
                ans.append(path[:])
            else:
                dfs(node.left, rem, path)
                dfs(node.right, rem, path)
            path.pop()

        if root:
            dfs(root, targetSum, [])
        return ans
class Solution {
public:
    vector<vector<int>> pathSum(TreeNode* root, int targetSum) {
        vector<vector<int>> ans;
        vector<int> path;
        dfs(root, targetSum, path, ans);
        return ans;
    }

private:
    void dfs(TreeNode* node, int rem, vector<int>& path, vector<vector<int>>& ans) {
        if (!node) return;
        path.push_back(node->val);
        rem -= node->val;
        if (!node->left && !node->right && rem == 0)
            ans.push_back(path);
        else {
            dfs(node->left, rem, path, ans);
            dfs(node->right, rem, path, ans);
        }
        path.pop_back();
    }
};
// 时间 O(n²) 最坏（路径拷贝），空间 O(h)

📈 复杂度分析

时间复杂度 O(n²)（最坏每条路径拷贝 O(h)，共 O(n) 个节点）
空间复杂度 O(h)（递归栈 + 当前 path，不计输出）

⚠️ 常见坑

❗ 未到叶子就收集：在中间节点 rem == 0 就把 path 加入答案，违反题意。

❗ 忘记回溯 pop：兄弟分支会带上上一分支的节点值，路径串掉。

❗ ans.append(path) 而非副本：后续 pop 会改动已存入的结果，必须用 path[:] 或 C++ 里 push 当前 vector 副本。

🔍 必测边界 Case

Case 1：空树
root = [], targetSum = 0 → []
Case 2：单节点匹配
root = [5], targetSum = 5 → [[5]]
Case 3：官方示例 1（两条路径）
targetSum = 22 → [[5,4,11,2],[5,8,4,5]]
Case 4：官方示例 2
root = [1,2,3], targetSum = 5 → []
Case 5：负值节点
root = [-2,null,-3], targetSum = -5 → [[-2,-3]]（路径和可为负，rem 仍按减法递推）
