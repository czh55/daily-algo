📋 题目描述

给你二叉树的根结点 root，请你将它展开为一个单链表：

  • 展开后的单链表同样使用 TreeNode，其中 right 子指针指向链表中下一个结点，左子指针始终为 null。
  • 展开后的单链表应与二叉树先序遍历顺序相同。

树中结点数在 [0, 2000] 内，节点值在 [-100, 100] 范围内。

示例 1

输入：root = [1,2,5,3,4,null,6]
输出：[1,null,2,null,3,null,4,null,5,null,6]
先序 1→2→3→4→5→6，全部挂在 right 上，left 均为空。

示例 2

输入：root = []
输出：[]

示例 3

输入：root = [0]
输出：[0]

💭 模拟答题者思考

1. 暴力直觉：先按先序把节点指针收集到数组，再第二遍把每个点的 left 置空、right 指向下一个——正确，但额外 O(n) 空间。

2. 重复在哪里？先序里「当前点的下一个」一定是：若有左子则左根，否则右子，否则回溯后的父的右子……可以在一次 DFS 里用「下一个是谁」直接改链，不必存数组。

3. 倒着拼链表：若已知先序中 node 之后的整段已变成单链头 prev，则令 node.right = prev、node.left = null，node 成为新头。要先知道 node 后面的结点，访问顺序必须是右子树 → 左子树 → 根。

4. 示例 1：处理 6 时 prev=null；5 连 6；4 连 5；… 最后 1 连 2，得到 1→2→3→4→5→6。

5. 进阶 O(1) 空间可用迭代「找左子树前驱接右子树」写法；本页用 prev 后序 DFS，时间 O(n)、栈 O(h)。

🧠 变量语义（先读这三句再编码）

变量类型语义（三句法）
prevTreeNode | null定义：在「已拼接好的链表」里，当前正在处理的节点在先序中的下一个结点（更靠右/更靠后访问）
维护：DFS 从右子树到左子树再到根，prev 始终是已处理后缀的头结点
更新：每处理完 node 后 prev = node；处理前令 node.right = prev、node.left = null
dfs(node)void定义：把以 node 为根的子树展开并接到全局 prev 链前面
维护：访问顺序为右 → 左 → 根（与先序相反的「后序」），保证根最后连上已拼好的右子树+左子树链
更新：空节点返回；否则 dfs(right)、dfs(left)，再改指针并更新 prev
rootTreeNode | null定义：输入输出同一棵树的根；展开后整棵树变成沿 right 的单链
维护：函数无返回值，原地改指针
更新：调用 dfs(root) 后从 root 沿 right 即为先序序列

⌨️ 落码步骤

1. 若 root 为空，直接返回

2. 定义外层可变 prev = None（或类成员 self.prev）

3. dfs(node)：空则返回；先 dfs(node.right)，再 dfs(node.left)

4. node.right = prev，node.left = None，prev = node

5. 对 root 调用 dfs，不返回值

💻 代码实现 

class Solution:
    def flatten(self, root: TreeNode | None) -> None:
        prev: TreeNode | None = None

        def dfs(node: TreeNode | None) -> None:
            nonlocal prev
            if not node:
                return
            dfs(node.right)
            dfs(node.left)
            node.right = prev
            node.left = None
            prev = node

        dfs(root)
class Solution {
    TreeNode* prev = nullptr;

    void dfs(TreeNode* node) {
        if (!node) return;
        dfs(node->right);
        dfs(node->left);
        node->right = prev;
        node->left = nullptr;
        prev = node;
    }

public:
    void flatten(TreeNode* root) {
        prev = nullptr;
        dfs(root);
    }
};
// 时间 O(n)，空间 O(h)

📈 复杂度分析

时间复杂度 O(n)
空间复杂度 O(h)（递归栈；链状树最坏 O(n)）

⚠️ 常见坑

❗ 按先序「根-左-右」直接递归改 right：还没处理完左子树就覆盖 right 指针，子树丢失——必须先处理右再左再根，或先用数组/栈。

❗ 忘记 node.left = nullptr：展开后仍保留左孩子，不符合「单链表、left 全为空」。

❗ 把 prev 当局部变量却在递归层各自新建：必须用 nonlocal / 成员变量，保证全树共享同一条「已拼后缀」。

🔍 必测边界 Case

Case 1：空树
root = [] → []（dfs 不修改）
Case 2：单节点
root = [0] → [0]（left、right 均为空）
Case 3：只有左链
root = [1,2,null,3] → 先序 1,2,3 全在 right 上
Case 4：官方示例 1
[1,2,5,3,4,null,6] → 1→2→3→4→5→6
Case 5：只有右子
root = [1,null,2,null,3] → 1→2→3（dfs 仍先右后左后根）
