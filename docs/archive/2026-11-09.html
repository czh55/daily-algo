二叉树中的最大路径和

📋 题目描述

二叉树中的路径被定义为一条节点序列，序列中每对相邻节点之间都存在一条边。同一个节点在一条路径序列中至多出现一次。该路径至少包含一个节点，且不一定经过根节点。

路径和是路径中各节点值的总和。

给你一个二叉树的根节点 root，返回其最大路径和。

示例 1

输入：root = [1,2,3]
输出：6
最优路径是 2 → 1 → 3，路径和为 2 + 1 + 3 = 6。

示例 2

输入：root = [-10,9,20,null,null,15,7]
输出：42
最优路径是 15 → 20 → 7，路径和为 15 + 20 + 7 = 42（不经过根 -10）。

💭 模拟答题者思考

1. 暴力：枚举任意两点之间的简单路径，对每条路径求和；点对数量 O(n²)、路径长度 O(n)，总体 O(n³) 或更糟，大树不可行。

2. 重复在哪里？固定「路径上最高的拐点节点」后，这条路径 = 左子树某条向下链 + 拐点值 + 右子树某条向下链——左右两侧的最大向下贡献对每个节点只需求一次。

3. 树形 DP / 后序：子问题「从某节点向下延伸的最大路径和」可递归；在当前节点用左右贡献拼出「经过该拐点」的候选答案，再向父节点只返回单侧最优（不能带分叉）。

4. 负值节点：子链贡献若为负，当作 0 丢弃即可（路径不必硬走该子树）；单节点路径至少包含一个节点，全局 ans 初值需覆盖全负树（如 root.val 或 -inf）。

5. 与 #543 直径、#112 路径和的区别：本题路径可从任意节点到任意节点、权重可为负；拐点模型天然处理「不经过根」的最优解（示例 2）。

🧠 变量语义（先读这三句再编码）

变量类型语义（三句法）
ansint定义：遍历全树过程中见到的、以某节点为拐点（向左拐、向右拐）的路径和最大值
维护：每访问一个节点，用 左贡献+root.val+右贡献 尝试刷新 ans
更新：ans = max(ans, left_gain + root.val + right_gain)
gain(root)int定义：从 root 出发、向下延伸的「单侧」最大路径和（父节点只能用这一条链，不能左右分叉）
维护：后序先拿左右子树返回值 gain(left)、gain(right)，负贡献裁成 0
更新：返回 root.val + max(left_gain, right_gain) 给父节点
left_gain / right_gainint定义：当前节点左/右子树向上能贡献的最大路径和（不含当前节点）
维护：max(0, gain(child))：子链为负则不作为拐点的一侧
更新：仅在本层算 ans 与返回值时使用，不向上传递分叉信息

⌨️ 落码步骤

1. 用成员 self.ans 记录全局最大路径和（初值可为负无穷或首节点值）

2. 定义 gain(node)：空节点返回 0；否则后序计算左右子 gain

3. left_gain = max(0, gain(left))，right_gain = max(0, gain(right))

4. 用 left_gain + node.val + right_gain 更新 self.ans

5. 向父返回 node.val + max(left_gain, right_gain)（单侧向下延伸）

6. 对 root 调用 gain 后返回 self.ans

💻 代码实现 

class Solution:
    def maxPathSum(self, root: TreeNode | None) -> int:
        self.ans = -10**9

        def gain(node: TreeNode | None) -> int:
            if not node:
                return 0
            left = max(0, gain(node.left))
            right = max(0, gain(node.right))
            self.ans = max(self.ans, left + node.val + right)
            return node.val + max(left, right)

        gain(root)
        return self.ans
class Solution {
    int ans = INT_MIN;

    int gain(TreeNode* node) {
        if (!node) return 0;
        int left = max(0, gain(node->left));
        int right = max(0, gain(node->right));
        ans = max(ans, left + node->val + right);
        return node->val + max(left, right);
    }

public:
    int maxPathSum(TreeNode* root) {
        gain(root);
        return ans;
    }
};
// 时间 O(n)，空间 O(h)（递归栈，h 为树高）

⚠️ 常见坑

❗ 向父节点返回时只能带单侧子树：node.val + max(left, right)，不能把 left+right 传上去，否则父层会重复分叉。

❗ 全局答案必须用「拐点公式」left+val+right 更新，不能只用返回值 gain(root)——根不一定是拐点（示例 2 最优路径不经过根）。

❗ 节点值可为负：max(0, gain(child)) 表示「子链为负则不要」；若整树皆负，ans 应为其中最大节点值，勿用 0 当初值。

🔍 必测边界 Case

Case 1：单节点
root = [5] → 5
Case 2：全负
root = [-3,-1,-2] → -1（选最大单节点）
Case 3：一侧为空
root = [2,-1] → 2（不走向负左子）
Case 4：题目示例 2
root = [-10,9,20,null,null,15,7] → 42（拐点在 20）
Case 5：长链 vs 短拐
root = [1,2,null,3] → 6（路径 3→2→1 或含拐点的组合，注意负贡献裁剪）
