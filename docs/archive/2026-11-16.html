📋 题目描述

给你一个字符串 s，请你将 s 分割成一些子串，使每个子串都是 回文串。返回 s 所有可能的分割方案。

子串为 s 中连续的一段，分割必须不重叠、按顺序覆盖整个 s，且每段都满足回文。题目保证 1 ≤ s.length ≤ 16，s 仅由小写英文字母组成。

示例 1

输入：s = "aab"
输出：[["a","a","b"],["aa","b"]]
先切 "a"|"a"|"b"，或切 "aa"|"b"（"aa" 是回文）；"a"|"ab" 非法因为 "ab" 不是回文。

示例 2

输入：s = "a"
输出：[["a"]]

💭 模拟答题者思考

1. 我先想暴力：在 s 的每个「缝隙」决定切或不切，共有 2^{n-1} 种切法，每种检查每段是否回文——思路对，但重复判断同一子串是否回文。

2. 重复在哪里？回溯时不断问「s[i..j] 是不是回文？」，朴素双指针每次 O(n)，分支又多。

3. 关键转化：按从左到右顺序切分，用 start 表示下一段起点；枚举本段终点 end，只有 s[start..end] 为回文才继续切后面——子问题变成「在 s[end+1:] 里继续找分割」，和 #93 复原 IP 是同一类「顺序切分 + 合法性剪枝」。

4. 预计算二维表 is_pal[i][j]：中心扩展思想压缩成 DP，区间从小到大填，O(n²) 一次建好，回溯每层 O(1) 查表。

5. 手推 s="aab"：start=0 可试 end=0（"a"）→ 递归得 "a","b" 与整条 "a","a","b"；end=1 得 "aa","b"；end=2 时 "aab" 非回文跳过。答案两组。n≤16 时搜索完全可行。

🧠 变量语义（先读这三句再编码）

变量类型语义（三句法）
is_pal[i][j]bool[n][n]定义：s[i..j]（含端点）是否为回文
维护：预处理后全程只读，供回溯 O(1) 判段合法性
更新：按区间长度递增填表：s[i]==s[j] 且（长度 ≤3 或 is_pal[i+1][j-1]）时为真
pathlist<str>定义：当前已确定的前缀切分（从左到右各段子串）
维护：DFS 每选定一段回文子串就 append，回溯时 pop
更新：仅当 start==n 时，将 path 的副本加入 ans
startint定义：下一段在 s 中的起始下标（含）
维护：每成功切出一段 s[start..end] 后，子问题从 end+1 继续
更新：初始为 0；枚举 end 从 start 到 n-1，仅当 is_pal[start][end] 才递归
anslist<list<str>>定义：所有合法分割方案
维护：只在用完整个字符串时收集一整条 path
更新：每到达叶子（start==n）追加 path[:] 一次

⌨️ 落码步骤

1. 记 n = len(s)，建 is_pal[n][n]，双重循环按区间长度填表

2. 初始化 ans = []、path = []

3. 定义 DFS backtrack(start)：若 start == n，将 path[:] 加入 ans 并返回

4. 对 end 从 start 到 n-1：若 not is_pal[start][end] 跳过；否则 path.append(s[start:end+1])，backtrack(end+1)，path.pop()

5. 从 backtrack(0) 启动，返回 ans

💻 代码实现 

class Solution:
    def partition(self, s: str) -> list[list[str]]:
        n = len(s)
        is_pal = [[False] * n for _ in range(n)]
        for j in range(n):
            for i in range(j, -1, -1):
                if s[i] == s[j] and (j - i < 2 or is_pal[i + 1][j - 1]):
                    is_pal[i][j] = True

        ans: list[list[str]] = []
        path: list[str] = []

        def backtrack(start: int) -> None:
            if start == n:
                ans.append(path[:])
                return
            for end in range(start, n):
                if not is_pal[start][end]:
                    continue
                path.append(s[start : end + 1])
                backtrack(end + 1)
                path.pop()

        backtrack(0)
        return ans
class Solution {
public:
    vector<vector<string>> partition(string s) {
        int n = s.size();
        vector<vector<bool>> isPal(n, vector<bool>(n, false));
        for (int j = 0; j < n; ++j) {
            for (int i = j; i >= 0; --i) {
                if (s[i] == s[j] && (j - i < 2 || isPal[i + 1][j - 1]))
                    isPal[i][j] = true;
            }
        }

        vector<vector<string>> ans;
        vector<string> path;

        function<void(int)> backtrack = [&](int start) {
            if (start == n) {
                ans.push_back(path);
                return;
            }
            for (int end = start; end < n; ++end) {
                if (!isPal[start][end]) continue;
                path.push_back(s.substr(start, end - start + 1));
                backtrack(end + 1);
                path.pop_back();
            }
        };

        backtrack(0);
        return ans;
    }
};
// 时间 O(n·2^n) 回溯 + O(n²) 预计算；空间 O(n²)

📈 复杂度分析

时间复杂度 O(n · 2^n)（回溯枚举切分；预计算回文表 O(n²)；|s|≤16 有上界）
空间复杂度 O(n²)（回文 DP 表 + 递归栈 ≤ n，不计输出）

⚠️ 常见坑

❗ 收集答案时用 path 引用而非副本：必须 ans.append(path[:]) 或 C++ 中在叶子层拷贝 path，否则后续 pop 会污染已存结果。

❗ 回文判错：长度为 1、2 时条件 j-i<2 要单独处理；不要写成 is_pal[i+1][j-1] 而未判边界导致越界或漏判。

❗ 子串必须连续：不能打乱字符顺序；每段是 s[start:end+1]，不是任意子序列。

🔍 必测边界 Case

Case 1：单字符
s = "a" → [["a"]]
Case 2：示例 aab
s = "aab" → [["a","a","b"],["aa","b"]]
Case 3：全书为回文
s = "aaa" → 四种切分（每个缝可切可不切且每段仍回文）
Case 4：无多字符回文段
s = "abc" → [["a","b","c"]]（只能逐字符切）
Case 5：较长重复
s = "aaaa" → 共 8 种合法分割（注意重叠枚举的是不同切点，不是同一子串重复使用）
