📋 题目描述

n 个孩子站成一排。给你一个整数数组 ratings 表示每个孩子的评分。

你需要按照以下要求给这些孩子分发糖果：

  • 每个孩子至少分配到 1 个糖果。
  • 相邻两个孩子中，评分更高的那个会获得更多的糖果。

请你给每个孩子分发糖果，计算并返回需要准备的最少糖果数目。

1 <= n == ratings.length <= 5 × 104，0 <= ratings[i] <= 5 × 104。

示例 1

输入：ratings = [1,0,2]
输出：5
可分别分发 2、1、2 颗糖果：中间评分最低只得 1 颗，左右高峰各比邻居多 1 颗。

示例 2

输入：ratings = [1,2,2]
输出：4
第二个孩子比第一个高需 2 颗；第三个与第二个评分相同不要求更多，只需 1 颗。共 1+2+1=4。

💭 模拟答题者思考

1. 暴力：每个孩子糖果数从 1 试到 n，检查全局是否满足相邻规则，可行则记入答案；指数级或高多项式，完全不现实。

2. 重复在哪里？「右边比我低我要多」和「左边比我低我要多」是同一类局部比较，却从两个方向互相牵扯：只从左贪心一次无法保证右侧下坡链，只从右一次又无法满足左侧上坡链。

3. 拆开约束：从左到右只 enforce「若评分涨，则比左邻多 1 颗」——任意下坡或相等处暂时仍为 1，先得到满足所有左向约束的最省分配。

4. 再从右到左：若比右邻高，则至少比右邻多 1；用 max 与左扫结果合并，因为左扫可能已在长上坡里给过更大糖果，不能右扫时减小。

5. 手推 [1,0,2]：左扫在 i=2 因 2>0 得 candies=[1,1,2]；右扫 i=0 因 1>0 令 c[0]=max(1,2)=2，最终 [2,1,2] 合计 5。两次线性扫描 O(n)、O(n) 空间存数组。

🧠 变量语义（先读这三句再编码）

变量类型语义（三句法）
candiesint[n]定义：每个孩子最终分到的糖果数，初值全为 1（满足「至少一颗」）
维护：同时满足「左邻居评分低则我多」与「右邻居评分低则我多」两条相邻约束
更新：从左扫调高右侧高峰；从右扫用 max 调高左侧高峰，避免覆盖已满足的约束
i（左扫）int定义：自左向右遍历时当前孩子下标
维护：只处理 ratings[i] > ratings[i-1] 的「上坡」关系
更新：若上坡则 candies[i] = candies[i-1] + 1，否则保持 1（下坡或平台不在此步强加约束）
i（右扫）int定义：自右向左遍历时当前孩子下标
维护：只处理 ratings[i] > ratings[i+1] 的「下坡对左侧更高」关系
更新：candies[i] = max(candies[i], candies[i+1] + 1)，取 max 是因为左扫可能已给更大值

⌨️ 落码步骤

1. n = len(ratings)，candies = [1] * n

2. 左扫 i=1..n-1：若 ratings[i] > ratings[i-1]，则 candies[i] = candies[i-1] + 1

3. 右扫 i=n-2..0：若 ratings[i] > ratings[i+1]，则 candies[i] = max(candies[i], candies[i+1] + 1)

4. 返回 sum(candies)

💻 代码实现 

class Solution:
    def candy(self, ratings: list[int]) -> int:
        n = len(ratings)
        candies = [1] * n
        for i in range(1, n):
            if ratings[i] > ratings[i - 1]:
                candies[i] = candies[i - 1] + 1
        for i in range(n - 2, -1, -1):
            if ratings[i] > ratings[i + 1]:
                candies[i] = max(candies[i], candies[i + 1] + 1)
        return sum(candies)
class Solution {
public:
    int candy(vector<int>& ratings) {
        int n = ratings.size();
        vector<int> candies(n, 1);
        for (int i = 1; i < n; ++i) {
            if (ratings[i] > ratings[i - 1])
                candies[i] = candies[i - 1] + 1;
        }
        for (int i = n - 2; i >= 0; --i) {
            if (ratings[i] > ratings[i + 1])
                candies[i] = max(candies[i], candies[i + 1] + 1);
        }
        long long total = 0;
        for (int c : candies) total += c;
        return (int)total;
    }
};
// 时间 O(n)，空间 O(n)；求和可用 long long

⚠️ 常见坑

❗ 右扫时直接赋值 candies[i] = candies[i+1] + 1 而不用 max：会覆盖左扫在长上坡里已满足的更大糖果数，破坏左侧约束。

❗ 评分相等时不能多给：只有严格 > 才加糖果；[1,2,2] 中第三人不能因「相邻」被迫拿 2 颗。

❗ 尝试一次遍历用单个变量维护：相邻约束是双向的，经典正确解需要两次方向扫描（或等价的增减数组技巧），一次扫无法同时最优。
