📋 题目描述

给定一个链表的头节点 head，返回链表开始入环的第一个节点；若链表无环，返回 null。

如果链表中有某个节点，可以通过连续跟踪 next 指针再次到达，则链表中存在环。评测系统内部用整数 pos 表示尾结点连回的位置（索引从 0 开始）；pos 为 -1 表示无环。注意：pos 不作为参数传入，且不允许修改链表。

0 <= 节点数 <= 104，-105 <= Node.val <= 105，pos 为 -1 或有效索引。

示例 1

输入：head = [3,2,0,-4], pos = 1
输出：返回索引为 1 的链表节点
尾部连接到第二个节点，入环点为值为 2 的节点。

示例 2

输入：head = [1,2], pos = 0
输出：返回索引为 0 的链表节点
尾连回头节点，入环点即 1 所在节点。

示例 3

输入：head = [1], pos = -1
输出：返回 null
单节点且 next 为空，无环。

💭 模拟答题者思考

1. 暴力：哈希表记录已访问节点，第一次重复访问的节点即入环点；时间 O(n)、空间 O(n)，可行但进阶要求 O(1) 额外空间。

2. 重复在哪里？#141 只问有没有环；本题还要定位入环点。若已知环长与相遇位置，可回推入环点，但环长未知时不能先扫一圈计数。

3. 先用 Floyd 判圈得到相遇点；无环则 fast 触达 null 直接返回空。有环时经典结论：设入环前长为 a、相遇点顺时针距入环点为 b、环长 c，则 2(a+b)=a+b+kc ⇒ a ≡ c-b (mod c)，故从 head 走 a 步与从相遇点走 a 步会同时到达入环点。

4. 落码：阶段一与 #141 相同；相遇后 slow = head，两者同步单步前进直至再次相遇，该节点即答案。

5. 手推示例 1：[3,2,0,-4] 尾连节点 2，入环点应为第二个节点；阶段二从 head=3 与相遇点同时出发，将在节点 2 汇合。

🧠 变量语义（先读这三句再编码）

变量类型语义（三句法）
slow / fastListNode*定义：第一阶段快慢指针，判环并求相遇点
维护：slow 每步走 1，fast 每步走 2；无环则 fast 先到尽头
更新：循环中同步推进；若相遇则说明有环
相遇点 meetListNode*定义：环内快慢指针第一次重合的节点（某次 slow == fast）
维护：存在环时必有；数学上距入环点沿环向前的步数，等于从 head 走到入环点的步数
更新：第一阶段结束时由 slow 与 fast 赋值
第二阶段 slowListNode*定义：求入环点时，一个指针从 head 出发、另一个从 meet 出发，同步每次走 1 步
维护：二者相遇的节点即为链表入环的第一个节点
更新：相遇后置 slow = head（或令 fast = head），再 while (slow != fast) { 同步 next }

⌨️ 落码步骤

1. slow = fast = head；while fast and fast.next：快慢推进，若 slow == fast 跳出（有环）

2. 若循环因 fast 为空结束，return None（无环）

3. slow = head；while slow != fast：二者各走 next 一步

4. 返回 slow（与 fast 同指向入环点）

💻 代码实现 

class Solution:
    def detectCycle(self, head: Optional[ListNode]) -> Optional[ListNode]:
        slow = fast = head
        while fast and fast.next:
            slow = slow.next
            fast = fast.next.next
            if slow is fast:
                slow = head
                while slow is not fast:
                    slow = slow.next
                    fast = fast.next
                return slow
        return None
class Solution {
public:
    ListNode *detectCycle(ListNode *head) {
        ListNode* slow = head;
        ListNode* fast = head;
        while (fast && fast->next) {
            slow = slow->next;
            fast = fast->next->next;
            if (slow == fast) {
                slow = head;
                while (slow != fast) {
                    slow = slow->next;
                    fast = fast->next;
                }
                return slow;
            }
        }
        return nullptr;
    }
};
// 时间 O(n)，空间 O(1)

⚠️ 常见坑

❗ 判环循环条件仍须 fast && fast->next，否则快指针双步会空指针解引用。

❗ 相遇后误把 slow 留在环内、只动 fast 也能做对，但教材写法是 slow = head 再双指针同步走——不要与阶段一的「快慢不等步」混在同一层循环里。

❗ 无环时返回 nullptr / None，不要返回相遇点或 head；#141 返回布尔，本题返回节点引用。

🔍 必测边界 Case

Case 1：无环
[1], pos = -1 → null（官方示例 3）
Case 2：整链成环（入环点为头）
[1,2], pos = 0 → 头节点（官方示例 2）
Case 3：长直线后入环
[3,2,0,-4], pos = 1 → 第二个节点（官方示例 1）
Case 4：空链表
head = null → null
