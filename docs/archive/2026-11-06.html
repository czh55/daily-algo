#121 贪心 简单

买卖股票的最佳时机

在 LeetCode 上查看 ↗

📋 题目描述

给定一个数组 prices ，它的第 i 个元素 prices[i] 表示一支给定股票第 i 天的价格。

你只能选择 某一天 买入这只股票，并选择在 未来的某一个不同的日子 卖出该股票。设计一个算法来计算你所能获取的最大利润。

返回你可以从这笔交易中获取的最大利润。如果你不能获取任何利润，返回 0 。

示例 1

输入：prices = [7,1,5,3,6,4]
输出：5
在第 2 天（股票价格 = 1）的时候买入，在第 5 天（股票价格 = 6）的时候卖出，最大利润 = 6-1 = 5 。注意利润不能是 7-1 = 6，因为卖出价格需要大于买入价格；同时，你不能在买入前卖出股票。

示例 2

输入：prices = [7,6,4,3,1]
输出：0
在这种情况下，没有交易完成，所以最大利润为 0。

💭 模拟答题者思考

1. 暴力：枚举所有 i < j，利润 prices[j] - prices[i]，取最大，O(n²)。

2. 重复在哪里？固定卖出日 j 时，最优买入一定是 0..j-1 上的最低价，不必对每个 j 再扫一遍左半边。

3. 一次扫描：从左到右维护「截至目前最低股价」min_price，每到新的一天，用「今天卖、历史最低买」更新答案。

4. 这等价于枚举所有合法买卖对，但把内层「找左边最小」压成 O(1) 均摊更新，整体 O(n)。

🧠 变量语义（先读这三句再编码）

变量类型语义（三句法）
min_priceint定义：扫描到当前天之前（含当天可选为买入日）见过的最低股价
维护：从左到右遍历，每步用当前价尝试刷新最小值
更新：min_price = min(min_price, price)，须在尝试用当天卖出更新答案之前或之后与当天价格比较，保证「先买后卖」
ansint定义：至多一笔交易（一次买、一次卖）能获得的最大利润
维护：初始为 0（允许不买不卖）
更新：枚举卖出日时 ans = max(ans, price - min_price)，其中 min_price 只能是当天左侧的历史最低价
priceint定义：循环中当前这一天的股价 prices[i]
维护：for price in prices 从左到右扫描
更新：每轮先用「历史最低买入价」与当天价算一笔候选利润，再决定是否刷新 min_price（顺序可先更新答案再更新最小值，或先算当日最小买入价为前一日最小再更新答案，二者等价）

⌨️ 落码步骤

1. 初始化 ans = 0，min_price = +∞（或第一天的价格）

2. 遍历每一天的价格 price

3. ans = max(ans, price - min_price)（若今天卖出，买入价必是历史最低）

4. min_price = min(min_price, price)（为后续天数提供更低买入价候选）

5. 返回 ans

💻 代码实现 

class Solution:
    def maxProfit(self, prices: list[int]) -> int:
        ans = 0
        min_price = float("inf")  # 截至目前见过的最低买入价
        for price in prices:
            ans = max(ans, price - min_price)
            min_price = min(min_price, price)
        return ans
class Solution {
public:
    int maxProfit(vector<int>& prices) {
        int ans = 0;
        int minPrice = INT_MAX;  // 截至目前见过的最低买入价
        for (int price : prices) {
            ans = max(ans, price - minPrice);
            minPrice = min(minPrice, price);
        }
        return ans;
    }
};
// 时间 O(n)，空间 O(1)

⚠️ 常见坑

❗ 必须先买后卖：枚举时只能用「当前天左侧」的最低价，不能把后面的低价拿来配前面的高价卖。

❗ ans 初值为 0：全程下跌时应输出 0，不能返回负利润。

❗ 与「可多次买卖」类题目区分：本题至多一笔交易，但一次扫描仍适用；多笔时需不同状态机或贪心策略。

🔍 必测边界 Case

Case 1：单调递减
prices = [7,6,4,3,1] → 0（怎么买都会亏，最优是不交易）
Case 2：仅两天且上涨
prices = [1,2] → 1
Case 3：单元素
prices = [5] → 0（没有「不同的卖出日」）
Case 4：价格全相同
prices = [3,3,3] → 0（无正利润）
Case 5：最低点在末尾
prices = [5,4,3,2] → 0（最低日在最后一天，无法在之后卖出获利）
