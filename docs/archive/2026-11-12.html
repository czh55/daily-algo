📋 题目描述

字典 wordList 中从单词 beginWord 到 endWord 的 转换序列 是一个按下述规格形成的序列 beginWord -> s1 -> s2 -> ... -> sk：

  • 每一对相邻的单词只差一个字母。
  • 对于 1 <= i <= k 时，每个 si 都在 wordList 中。注意，beginWord 不需要在 wordList 中。
  • sk == endWord

给你两个单词 beginWord、endWord 和一个字典 wordList，返回从 beginWord 到 endWord 的 最短转换序列 中的 单词数目。如果不存在这样的转换序列，返回 0。

示例 1

输入：beginWord = "hit", endWord = "cog", wordList = ["hot","dot","dog","lot","log","cog"]
输出：5
一个最短转换序列是 "hit" -> "hot" -> "dot" -> "dog" -> "cog"，返回长度 5（含首尾）。

示例 2

输入：beginWord = "hit", endWord = "cog", wordList = ["hot","dot","dog","lot","log"]
输出：0
endWord "cog" 不在字典中，无法进行转换。

💭 模拟答题者思考

1. 暴力：DFS 枚举所有 begin→end 的单词链，记录最短长度——分支因子大、路径指数级，且要搜完才知道最短，不可行。

2. 重复在哪里？求「最少几步」等价于无权图上两点最短路；边权均为 1，应先按距离分层扩展，而不是深搜到底再比长短。

3. 建模：每个单词是顶点；若两词只差一位字母且目标词在字典中，则连无向边。答案为 beginWord 到 endWord 的最短路上的顶点数（含起点）。

4. 层序 BFS：队列维护 (词, 当前序列长度)；首次扩展到 endWord 时返回 len+1（或当前层数 +1），即最短单词数目。

5. 与 #126 对比：本题只要最短长度，不必 DFS 收集全部路径；BFS 首次命中终点即可停，无需在本层全部扩展完再 DFS。

🧠 变量语义（先读这三句再编码）

变量类型语义（三句法）
wordsset<str>定义：当前仍可被 BFS 扩展的字典词集（含 endWord，可从集合中剔除起点以去重）
维护：某词首次入队时从 words 中移除，保证每个词最多被访问一次
更新：初始化 set(wordList)；若 endWord ∉ words 直接返回 0
qdeque定义：BFS 队列，元素为 (当前单词 w, 当前序列长度 len)，len 含 beginWord
维护：队头出队扩展邻居；层序写法亦可按层维护距离
更新：起点 (beginWord, 1) 入队；发现未访问邻居 nw 时 (nw, len+1) 入队
neighbors(w)迭代器定义：与 w 仅差一个字母、且仍在 words（或词表）中的全部单词
维护：逐位把 w[i] 换成 a–z 后查集合
更新：每扩展一个 w 枚举全部合法 nw

⌨️ 落码步骤

1. words = set(wordList)；若 endWord 不在集合中，返回 0

2. 实现 neighbors(w)：每位替换 a–z，命中仍在 words 的词则 yield

3. 队列入 (beginWord, 1)；可将 beginWord 从 words 移除（若存在）避免重复

4. BFS：出队 (w, d)；对每个 nw ∈ neighbors(w)，若 nw == endWord 返回 d+1；否则从 words 删掉 nw 并 (nw, d+1) 入队

5. 队列空仍未到达终点，返回 0

💻 代码实现 

from collections import deque

class Solution:
    def ladderLength(self, beginWord: str, endWord: str, wordList: list[str]) -> int:
        words = set(wordList)
        if endWord not in words:
            return 0
        words.discard(beginWord)

        L = len(beginWord)

        def neighbors(w: str):
            for i in range(L):
                for c in "abcdefghijklmnopqrstuvwxyz":
                    if c == w[i]:
                        continue
                    nw = w[:i] + c + w[i + 1 :]
                    if nw in words:
                        yield nw

        q = deque([(beginWord, 1)])
        while q:
            w, d = q.popleft()
            for nw in neighbors(w):
                if nw == endWord:
                    return d + 1
                words.remove(nw)
                q.append((nw, d + 1))
        return 0
class Solution {
public:
    int ladderLength(string beginWord, string endWord, vector<string>& wordList) {
        unordered_set<string> words(wordList.begin(), wordList.end());
        if (!words.count(endWord)) return 0;
        words.erase(beginWord);

        int L = (int)beginWord.size();
        auto neighbors = [&](const string& w) {
            vector<string> res;
            for (int i = 0; i < L; ++i) {
                for (char c = 'a'; c <= 'z'; ++c) {
                    if (c == w[i]) continue;
                    string nw = w;
                    nw[i] = c;
                    if (words.count(nw)) res.push_back(nw);
                }
            }
            return res;
        };

        queue<pair<string, int>> q;
        q.push({beginWord, 1});
        while (!q.empty()) {
            auto [w, d] = q.front();
            q.pop();
            for (const string& nw : neighbors(w)) {
                if (nw == endWord) return d + 1;
                words.erase(nw);
                q.push({nw, d + 1});
            }
        }
        return 0;
    }
};
// 时间 O(N·L²·26)，空间 O(N·L)

⚠️ 常见坑

❗ 返回「边数」而非「单词数」：最短链 hit→…→cog 共 5 个词，应返回 5，不是 4 步变换。

❗ 未先判断 endWord 是否在 wordList：与题意一致，不在则必须返回 0。

❗ 邻居已在 BFS 中访问仍重复入队：应用 visited 或从 words 中删除已扩展词，否则队列爆炸、时间超限。
