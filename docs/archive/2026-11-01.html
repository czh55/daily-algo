#116 树层序BFS 中等

填充每个节点的下一个右侧节点指针

📋 题目描述

给定一个完美二叉树（所有叶子在同一层、每个父节点都有两个孩子），节点定义含 val, left, right, next。请填充每个 next，使其指向同一层的下一个右侧节点；若无右侧邻居则置 NULL。初始时所有 next 均为 NULL。

进阶：只能使用常量级额外空间（递归栈不算额外空间）。

节点数 [0, 212-1]，-1000 ≤ val ≤ 1000。

示例 1

输入：root = [1,2,3,4,5,6,7]
输出：[1,#,2,3,#,4,5,6,7,#]
层序序列化中 # 表示每层结束；同一层由 next 横向串联（1→2→3，4→5→6→7）。

示例 2

输入：root = []
输出：[]

💭 模拟答题者思考

1. 暴力直觉：层序 BFS，用队列按层收集节点，每层从左到右依次 prev.next = curr——正确，但队列最坏 O(n) 额外空间，不满足进阶的 O(1) 要求。

2. 重复在哪里？同一层节点之间的「谁连谁」只取决于树结构；完美树每层是满的，下一层最左节点永远是当前层最左节点的 left，不必再用队列记层界。

3. 关键观察：处理第 k 层时，第 k 层的 next 已经填好，可以把第 k 层当作链表，用 curr = curr.next 遍历，同时在遍历过程中把第 k+1 层的 next 连起来。

4. 手推示例 1 第一层：curr=1，1.left.next=2，1.right.next=3（因 1.next 为空，右孩子无跨父兄弟）。第二层：curr=2 时 4.next=5；curr=3 时 6.next=7，且 5.next=6 来自 2.right.next = 2.next.left。

5. 外层 while leftmost.left、内层 while curr，每个节点常数工作，时间 O(n)；除指针外无额外容器，空间 O(1)。

🧠 变量语义（先读这三句再编码）

变量类型语义（三句法）
leftmostNode*定义：当前正在处理的层的最左节点，初始为 root
维护：每处理完一整层后，下一层的最左节点一定是 leftmost.left（完美树每层满）
更新：内层 while curr 结束后令 leftmost = leftmost.left；若无左孩子则整棵树已处理完
currNode*定义：在当前层从左到右行走的指针，沿已填好的 next 前进
维护：访问顺序与层序从左到右一致，且先用 curr 连好下一层的 next，再 curr = curr.next
更新：每轮：curr.left.next = curr.right；若 curr.next 非空则 curr.right.next = curr.next.left
prev（BFS 版）Node*定义：队列扩展时，本层已出队节点中的「上一个」节点
维护：与 node 同层时 prev.next = node；换层时重置为 NULL
更新：每出队一个节点后 prev = node；层末 prev 的 next 保持 NULL

⌨️ 落码步骤

1. 若 root 为空，直接返回

2. leftmost = root；当 leftmost.left 存在（还有下一层）时循环

3. curr = leftmost；内层沿 curr.next 走：先 curr.left.next = curr.right

4. 若 curr.next != NULL，令 curr.right.next = curr.next.left（跨父节点连右侧子树）

5. curr = curr.next；内层结束后 leftmost = leftmost.left，进入下一层

6. 返回 root（所有 next 已原地写好）

💻 代码实现 

class Solution:
    def connect(self, root: "Optional[Node]") -> "Optional[Node]":
        if not root:
            return None
        leftmost = root
        while leftmost.left:          # 完美树：有左孩子 ⇔ 还有下一层
            curr = leftmost
            while curr:
                curr.left.next = curr.right
                if curr.next:
                    curr.right.next = curr.next.left
                curr = curr.next
            leftmost = leftmost.left
        return root
class Solution {
public:
    Node* connect(Node* root) {
        if (!root) return nullptr;
        Node* leftmost = root;
        while (leftmost->left) {
            Node* curr = leftmost;
            while (curr) {
                curr->left->next = curr->right;
                if (curr->next)
                    curr->right->next = curr->next->left;
                curr = curr->next;
            }
            leftmost = leftmost->left;
        }
        return root;
    }
};
// 时间 O(n)，空间 O(1)

⚠️ 常见坑

❗ 把 #117（非完美树）的写法直接搬来：本题保证每层满，可安全用 leftmost.left 下移；非完美树需 BFS 或更复杂的指针技巧。

❗ 内层用 left/right 走下一层而不用 next：会破坏「O(1) 层序」思路，且与已填好的横向链不一致；应用 curr = curr.next 扫当前层。

❗ 忘记 curr.next 判空就写 curr.right.next = curr.next.left：层末节点的右孩子 next 必须保持 NULL。

🔍 必测边界 Case

Case 1：空树
root = [] → []
Case 2：单节点
root = [1] → [1,#]（无子层，next 仍为 NULL）
Case 3：两层完美树
root = [1,2,3] → 1.next=2, 2.next=3, 3.next=NULL
Case 4：官方示例 1
root = [1,2,3,4,5,6,7] → 层 1: 1→2→3；层 2: 4→5→6→7
Case 5：最深层仅一个节点（仍完美）
高度 h 的完美树最左叶子 next 链应串满该层
