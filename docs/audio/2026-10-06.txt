题目描述。n 位格雷码序列 是一个由 2n 个整数组成的序列，其中：

每个整数都在范围 [0, 2n - 1] 内（含 0 和 2n - 1）

第一个整数是 0

一个整数在序列中出现 不超过一次

每对 相邻 整数的二进制表示 恰好一位不同，且

第一个 和 最后一个 整数的二进制表示 恰好一位不同

给你一个整数 n，返回任一有效的 n 位格雷码序列。

示例。示例 1

    输入：n = 2。示例 2

    输入：n = 1

先模拟答题者的思考过程，从暴力解法出发，找到重复劳动，再推导优化方向。

1. 我先写暴力：用回溯枚举 0..2^n-1 的全排列，检查相邻与首尾是否仅一位不同——能出答案，但阶乘级搜索，n=16 时完全不可行。

2. 重复在哪里？合法的格雷码有固定构造规律：n 位序列总可以看成「n-1 位序列」与它的镜像（每位最高位翻转）首尾相接，且连接处仍只差一位。

3. 反射法：从 result = [0] 出发，对每一位 i，把 result 逆序遍历，把每个数 OR 上 1<<i 后追加到尾部——长度每轮 ×2，且相邻性由归纳保证。

4. 等价公式 gray(i) = i ^ (i >> 1)：按自然序 i 映射即得标准格雷码；实现更短，但「为什么相邻只差一位」不如反射法直观，面试可先讲反射再提公式。

5. 共生成 2^n 个数，每数 O(1) 处理，时间 O(2^n)；输出本身占 O(2^n) 空间。

接下来是变量语义，先理解每个变量的定义、维护和更新，再开始编码。

变量 result，类型 list<int>。定义：当前已构造的格雷码前缀，长度始终为 2^k（k 为已处理位数）
维护：初始为 [0]，表示 0 位格雷码只有 0
更新：每增加一位时，在末尾追加「原序列逆序 + 最高位为 1」的镜像段

变量 i，类型 int。定义：当前要插入的新二进制位所在位置（从低位 0 起）
维护：for i in range(n)，每轮把序列长度翻倍
更新：每轮结束后 i += 1；镜像时用掩码 1 << i

变量 mask，类型 int。定义：本轮要在旧格雷码上点亮的最高位，值为 1 << i
维护：与 result 中每个元素按位 OR，得到镜像半段
更新：随 i 每轮重新计算

落码步骤如下。

1. result = [0]

2. 对 i = 0 .. n-1：mask = 1 << i，令 result += [x | mask for x in reversed(result)]（C++ 可对前半段逆序追加）

3. 返回 result（长度已为 2^n，首项为 0）

复杂度分析。时间复杂度 O(2^n)，空间复杂度 O(2^n)（输出序列，不计则 O(1)）。

常见坑点，请注意。

&#x2757; 镜像时忘记逆序追加：若按正序 OR mask，相邻项可能差多位，首尾也不满足格雷性质。

&#x2757; 把「自然二进制序」0,1,2,… 直接当作答案——例如 n=2 时 [0,1,2,3] 中 1 与 2 的二进制差两位。

&#x2757; 回溯写法未用 used 位集去重：同一数字出现两次会立即违反题意。
