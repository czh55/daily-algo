题目描述。给你二叉树的根节点 root，返回其节点值的 自底向上的层序遍历（即按从叶子节点所在层到根节点所在的层，逐层从左向右遍历）。
节点数目在 [0, 2000] 内，节点值在 [-1000, 1000] 范围内。

示例。示例 1

    输入：root = [3,9,20,null,null,15,7]。示例 2

    输入：root = [1]。示例 3

    输入：root = []

先模拟答题者的思考过程，从暴力解法出发，找到重复劳动，再推导优化方向。

1. 暴力直觉：和 #102 一样 BFS 得到 [[3],[9,20],[15,7]]，最后把整个外层列表反转——思路直接，代码也最短。

2. 重复在哪里？层内收集逻辑与 #102 完全相同，唯一差别是输出顺序：根层应在最后，叶子层应在最前。

3. 两种等价写法：① BFS 正常 append 每层，结束 ans.reverse()；② 每收集完一层就 ans.insert(0, level) 或双端队列 appendleft，省一次反转但单层插入头是 O(层数)，总仍 O(n²) 最坏——面试推荐先 BFS 再反转，整体 O(n) 且清晰。

4. 示例 1：BFS 得顶向下 [[3],[9,20],[15,7]]，反转后 [[15,7],[9,20],[3]]。

5. 每个节点仍只入队出队一次，时间 O(n)；空间 O(n)。

接下来是变量语义，先理解每个变量的定义、维护和更新，再开始编码。

变量 q，类型 deque<TreeNode*>。定义：BFS 队列，与 #102 相同，按层从左到右扩展
维护：每轮处理固定 size 个节点，保证一层一层推进
更新：弹出节点后将其非空孩子按左，得到右入队

变量 level，类型 list<int>。定义：当前层从左到右的节点值
维护：本轮内每弹出一个节点追加 val
更新：一层收集完后写入结果（见 ans）

变量 ans，类型 list<list<int>>。定义：自底向上的层序结果，ans[0] 为最底层
维护：可先按顶向下 BFS 收集再整体 reverse，或每层 insert(0, level) / appendleft
更新：每完成一层即按题意顺序并入；空树返回 []

落码步骤如下。

1. 若 root 为空，返回 []

2. 用与 #102 相同的 BFS：队列、每层 size = len(q)、收集 level 并 ans.append(level)

3. BFS 结束后执行 ans.reverse()（或循环里每层 ans.insert(0, level)）

4. 返回 ans

复杂度分析。时间复杂度 O(n)，空间复杂度 O(n)（队列最坏存满一层，约 n/2 个节点）。

常见坑点，请注意。

&#x2757; 忘记反转：直接返回 #102 的结果，根层在前，与题意相反。

&#x2757; 在 BFS 内每层 reverse(level)：题意只要求「层与层」自底向上，层内仍从左到右，不要颠倒同层顺序。

&#x2757; 与 #102 相同：不用固定 size 会导致层界混乱；空树须返回 []。

必测的边界情况。

Case 1：空树

Case 2：单节点

Case 3：官方示例 1

Case 4：只有左孩子（链）
