题目描述。给你二叉树的根结点 root，请你将它展开为一个单链表：

展开后的单链表同样使用 TreeNode，其中 right 子指针指向链表中下一个结点，左子指针始终为 null。

展开后的单链表应与二叉树先序遍历顺序相同。

树中结点数在 [0, 2000] 内，节点值在 [-100, 100] 范围内。

示例。示例 1

    输入：root = [1,2,5,3,4,null,6]。示例 2

    输入：root = []。示例 3

    输入：root = [0]

先模拟答题者的思考过程，从暴力解法出发，找到重复劳动，再推导优化方向。

1. 暴力直觉：先按先序把节点指针收集到数组，再第二遍把每个点的 left 置空、right 指向下一个——正确，但额外 O(n) 空间。

2. 重复在哪里？先序里「当前点的下一个」一定是：若有左子则左根，否则右子，否则回溯后的父的右子……可以在一次 DFS 里用「下一个是谁」直接改链，不必存数组。

3. 倒着拼链表：若已知先序中 node 之后的整段已变成单链头 prev，则令 node.right = prev、node.left = null，node 成为新头。要先知道 node 后面的结点，访问顺序必须是右子树 ，得到 左子树 ，得到 根。

4. 示例 1：处理 6 时 prev=null；5 连 6；4 连 5；… 最后 1 连 2，得到 1，得到2，得到3，得到4，得到5，得到6。

5. 进阶 O(1) 空间可用迭代「找左子树前驱接右子树」写法；本页用 prev 后序 DFS，时间 O(n)、栈 O(h)。

接下来是变量语义，先理解每个变量的定义、维护和更新，再开始编码。

变量 prev，类型 TreeNode | null。定义：在「已拼接好的链表」里，当前正在处理的节点在先序中的下一个结点（更靠右/更靠后访问）
维护：DFS 从右子树到左子树再到根，prev 始终是已处理后缀的头结点
更新：每处理完 node 后 prev = node；处理前令 node.right = prev、node.left = null

变量 dfs(node)，类型 void。定义：把以 node 为根的子树展开并接到全局 prev 链前面
维护：访问顺序为右 ，得到 左 ，得到 根（与先序相反的「后序」），保证根最后连上已拼好的右子树+左子树链
更新：空节点返回；否则 dfs(right)、dfs(left)，再改指针并更新 prev

变量 root，类型 TreeNode | null。定义：输入输出同一棵树的根；展开后整棵树变成沿 right 的单链
维护：函数无返回值，原地改指针
更新：调用 dfs(root) 后从 root 沿 right 即为先序序列

落码步骤如下。

1. 若 root 为空，直接返回

2. 定义外层可变 prev = None（或类成员 self.prev）

3. dfs(node)：空则返回；先 dfs(node.right)，再 dfs(node.left)

4. node.right = prev，node.left = None，prev = node

5. 对 root 调用 dfs，不返回值

复杂度分析。时间复杂度 O(n)，空间复杂度 O(h)（递归栈；链状树最坏 O(n)）。

常见坑点，请注意。

&#x2757; 按先序「根-左-右」直接递归改 right：还没处理完左子树就覆盖 right 指针，子树丢失——必须先处理右再左再根，或先用数组/栈。

&#x2757; 忘记 node.left = nullptr：展开后仍保留左孩子，不符合「单链表、left 全为空」。

&#x2757; 把 prev 当局部变量却在递归层各自新建：必须用 nonlocal / 成员变量，保证全树共享同一条「已拼后缀」。
