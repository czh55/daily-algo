题目描述。给你二叉树的根节点 root 和一个整数目标和 targetSum，找出所有 从根节点到叶子节点 路径总和等于给定目标和的路径。
叶子节点 是指没有子节点的节点。
树中节点总数在范围 [0, 5000] 内，节点值与 targetSum 均在 [-1000, 1000] 范围内。

示例。示例 1

    输入：root = [5,4,8,11,null,13,4,7,2,null,null,5,1], targetSum = 22。示例 2

    输入：root = [1,2,3], targetSum = 5。示例 3

    输入：root = [1,2], targetSum = 0

先模拟答题者的思考过程，从暴力解法出发，找到重复劳动，再推导优化方向。

1. 暴力直觉：枚举每条根到叶的路径，把节点值列出来并求和，等于 targetSum 就加入答案——与 #112 判断「是否存在」同型，只是要收集全部合法路径。

2. 重复在哪里？共享前缀的多条路径会在同一祖先上重复维护「当前路径序列」和「剩余目标和」——适合一条 DFS 上用公共 path，分叉时回溯撤销。

3. 前序 + 回溯：到节点 u 时 path.append(u.val)、rem -= u.val；若 u 是叶子且 rem==0 则 ans.append(path[:])；否则递归非空孩子；返回前 path.pop()。

4. 与 #112 的差异：不能一发现 rem==0 就停——必须到叶子；也不能只返回 bool，要在叶子层拷贝整条 path。

5. 每个节点进出各一次，时间 O(n)；输出路径总长最坏 O(n²)，递归栈 O(h)。

接下来是变量语义，先理解每个变量的定义、维护和更新，再开始编码。

变量 path，类型 list<int>。定义：从根到当前 DFS 节点的节点值序列（不含尚未访问的孩子）
维护：进入节点前 append(node.val)，离开该子树前 pop() 撤销
更新：前序「选当前点 ，得到 递归孩子 ，得到 撤销」；只在叶子且 rem==0 时把 path[:] 记入答案

变量 rem，类型 int。定义：沿当前 path 走到叶子时，路径和还差多少才等于原 targetSum
维护：每进入节点 rem -= node.val；传给左右孩子的是扣减后的同一 rem
更新：与 #112 相同：仅叶子允许用 rem == 0 判定成功，中间节点不能提前收集

变量 ans，类型 list<list<int>>。定义：所有满足条件的根到叶路径集合
维护：DFS 过程中只追加完整路径的副本，不存前缀
更新：if 叶子 and rem==0: ans.append(path[:])

落码步骤如下。

1. 若 root 为空，返回 []

2. 定义 dfs(node, rem, path)：空节点直接返回

3. path.append(node.val)，rem -= node.val

4. 若 node 为叶子且 rem == 0，ans.append(path[:])

5. 否则分别 dfs(left, rem, path)、dfs(right, rem, path)

6. 回溯：path.pop()；对外 dfs(root, targetSum, []) 后返回 ans

复杂度分析。时间复杂度 O(n²)（最坏每条路径拷贝 O(h)，共 O(n) 个节点），空间复杂度 O(h)（递归栈 + 当前 path，不计输出）。

常见坑点，请注意。

&#x2757; 未到叶子就收集：在中间节点 rem == 0 就把 path 加入答案，违反题意。

&#x2757; 忘记回溯 pop：兄弟分支会带上上一分支的节点值，路径串掉。

&#x2757; ans.append(path) 而非副本：后续 pop 会改动已存入的结果，必须用 path[:] 或 C++ 里 push 当前 vector 副本。
