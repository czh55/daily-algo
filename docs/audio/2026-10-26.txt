题目描述。给定一个二叉树，判断它是否是平衡二叉树。
平衡二叉树是指：二叉树的每个节点的左右两个子树的高度差的绝对值不超过 1。
树中节点数在 [0, 5000] 内，节点值在 [-104, 104] 范围内。

示例。示例 1

    输入：root = [3,9,20,null,null,15,7]。示例 2

    输入：root = [1,2,2,3,3,null,null,4,4]。示例 3

    输入：root = []

先模拟答题者的思考过程，从暴力解法出发，找到重复劳动，再推导优化方向。

1. 暴力直觉：对每个节点分别算左右子树高度（两次 #104），比较差值是否 ≤ 1，再递归左右孩子是否平衡——正确，但共享子树会被重复算高度，最坏 O(n²)。

2. 重复在哪里？「子树是否平衡」与「子树高度」在同一次后序遍历里就能一并得出，不必为每个节点单独再起一套高度 DFS。

3. 自底向上：后序先拿左右高度；若某侧已是 -1（子树已不平衡）直接向上传 -1；若 |left-right| > 1 当前子树也不平衡，返回 -1；否则返回 1 + max(left, right) 供父节点使用。

4. 示例 2：最深不平衡出现在节点 3，左高 2、右高 0，该层 dfs 返回 -1，一路传到根，isBalanced 为 false。

5. 每个节点访问常数次，时间 O(n)；递归栈 O(h)。

接下来是变量语义，先理解每个变量的定义、维护和更新，再开始编码。

变量 dfs(node)，类型 int。定义：以 node 为根的子树若平衡则返回其高度（空树 0）；若已发现不平衡则返回 -1 作哨兵
维护：后序汇总左右子树高度后，在当前节点处校验 |left - right| ≤ 1
更新：左右任一返回 -1 则向上传播 -1；否则 return 1 + max(left, right)

变量 left, right，类型 int。定义：当前节点左、右子树的高度（由子递归 dfs 给出）
维护：子树必须已平衡，否则值为 -1，父层不再计算差值
更新：left = dfs(node.left)，right = dfs(node.right)

变量 isBalanced(root)，类型 bool。定义：整棵树是否平衡
维护：等价于「自顶向下一次 DFS 能否走完且从未触发哨兵」
更新：return dfs(root) != -1

落码步骤如下。

1. 定义 dfs(node)：若 node 为空返回 0

2. left = dfs(node.left)，若 left == -1 返回 -1

3. right = dfs(node.right)，若 right == -1 返回 -1

4. 若 abs(left - right) > 1 返回 -1，否则 return 1 + max(left, right)

5. isBalanced 返回 dfs(root) != -1

复杂度分析。时间复杂度 O(n)，空间复杂度 O(h)（递归栈，h 为树高；链状树最坏 O(n)）。

常见坑点，请注意。

&#x2757; 只检查根节点左右高度差：子树内部不平衡也会被判为 false，必须递归或在一次 DFS 里让子树结果参与判断。

&#x2757; 高度定义与 #104 不一致：本题高度是节点层数（空 0、单节点 1），差值比较要用同一套定义。

&#x2757; 发现不平衡仍继续算高度：应尽早返回哨兵 -1，避免无意义遍历（朴素双 DFS 虽能过中小数据，但面试应写 O(n) 版）。

Case 4：官方示例 2（不平衡）

Case 5：仅根不平衡、一侧为空
