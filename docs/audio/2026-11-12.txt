题目描述。字典 wordList 中从单词 beginWord 到 endWord 的 转换序列 是一个按下述规格形成的序列 beginWord -> s1 -> s2 -> ... -> sk：

    每一对相邻的单词只差一个字母。

    对于 1 <= i <= k 时，每个 si 都在 wordList 中。注意，beginWord 不需要在 wordList 中。

    sk == endWord

给你两个单词 beginWord、endWord 和一个字典 wordList，返回从 beginWord 到 endWord 的 最短转换序列 中的 单词数目。如果不存在这样的转换序列，返回 0。

示例。示例 1

    输入：beginWord = "hit", endWord = "cog", wordList = ["hot","dot","dog","lot","log","cog"]。示例 2

    输入：beginWord = "hit", endWord = "cog", wordList = ["hot","dot","dog","lot","log"]

先模拟答题者的思考过程，从暴力解法出发，找到重复劳动，再推导优化方向。

1. 暴力：DFS 枚举所有 begin，得到end 的单词链，记录最短长度——分支因子大、路径指数级，且要搜完才知道最短，不可行。

2. 重复在哪里？求「最少几步」等价于无权图上两点最短路；边权均为 1，应先按距离分层扩展，而不是深搜到底再比长短。

3. 建模：每个单词是顶点；若两词只差一位字母且目标词在字典中，则连无向边。答案为 beginWord 到 endWord 的最短路上的顶点数（含起点）。

4. 层序 BFS：队列维护 (词, 当前序列长度)；首次扩展到 endWord 时返回 len+1（或当前层数 +1），即最短单词数目。

5. 与 #126 对比：本题只要最短长度，不必 DFS 收集全部路径；BFS 首次命中终点即可停，无需在本层全部扩展完再 DFS。

接下来是变量语义，先理解每个变量的定义、维护和更新，再开始编码。

变量 words，类型 set<str>。定义：当前仍可被 BFS 扩展的字典词集（含 endWord，可从集合中剔除起点以去重）
维护：某词首次入队时从 words 中移除，保证每个词最多被访问一次
更新：初始化 set(wordList)；若 endWord ∉ words 直接返回 0

变量 q，类型 deque。定义：BFS 队列，元素为 (当前单词 w, 当前序列长度 len)，len 含 beginWord
维护：队头出队扩展邻居；层序写法亦可按层维护距离
更新：起点 (beginWord, 1) 入队；发现未访问邻居 nw 时 (nw, len+1) 入队

变量 neighbors(w)，类型 迭代器。定义：与 w 仅差一个字母、且仍在 words（或词表）中的全部单词
维护：逐位把 w[i] 换成 a–z 后查集合
更新：每扩展一个 w 枚举全部合法 nw

落码步骤如下。

1. words = set(wordList)；若 endWord 不在集合中，返回 0

2. 实现 neighbors(w)：每位替换 a–z，命中仍在 words 的词则 yield

3. 队列入 (beginWord, 1)；可将 beginWord 从 words 移除（若存在）避免重复

4. BFS：出队 (w, d)；对每个 nw ∈ neighbors(w)，若 nw == endWord 返回 d+1；否则从 words 删掉 nw 并 (nw, d+1) 入队

5. 队列空仍未到达终点，返回 0

复杂度分析。时间复杂度 O(N·L²·26)，空间复杂度 O(N·L)。

常见坑点，请注意。

&#x2757; 返回「边数」而非「单词数」：最短链 hit，得到…，得到cog 共 5 个词，应返回 5，不是 4 步变换。

&#x2757; 未先判断 endWord 是否在 wordList：与题意一致，不在则必须返回 0。

&#x2757; 邻居已在 BFS 中访问仍重复入队：应用 visited 或从 words 中删除已扩展词，否则队列爆炸、时间超限。

必测的边界情况。

Case 1：终点不在字典

Case 2：无法连通

Case 3：一步直达

Case 4：begin 恰在 wordList
