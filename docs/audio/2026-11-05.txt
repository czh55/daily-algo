题目描述。给定一个三角形 triangle，找出自顶向下的最小路径和。
每一步只能移动到下一行中相邻的结点上：若当前位于下标 i，下一步可到下标 i 或 i + 1。
1 ≤ triangle.length ≤ 200，第 i 行有 i+1 个数，元素范围 [-10⁴, 10⁴]。

示例。示例 1

    输入：triangle = [[2],[3,4],[6,5,7],[4,1,8,3]]。示例 2

    输入：triangle = [[-10]]

先模拟答题者的思考过程，从暴力解法出发，找到重复劳动，再推导优化方向。

1. 暴力：从顶点 DFS，每步向左下或右下，到底部累加路径和，取全局最小——正确，但分支约 2^(n-1)，n≤200 必超时。

2. 重复在哪里？子问题「从 (i,j) 往下走的最小和」只依赖下一行的 (i+1,j) 与 (i+1,j+1)，同一格会被多条上层路径重复计算——典型 DP。

3. 自顶向下：f(i,j) = triangle[i][j] + min(f(i+1,j), f(i+1,j+1))，记忆化或表格；自底向上等价且更自然：最后一行已是答案片段，往上每层把「选哪条腿更便宜」加进当前格。

4. 手推示例 1 最底行不动；倒数第二行 [4,1,8,3] 上一行 [6,5,7]：6+=min(4,1)=7，5+=min(1,8)=6，7+=min(8,3)=10；再往上得顶 2+min(9,10)=11。

5. 允许改输入时直接在 triangle 上原地 DP，额外空间 O(1)；否则另开 O(n) 的一行滚动数组。

接下来是变量语义，先理解每个变量的定义、维护和更新，再开始编码。

变量 triangle[i][j]（原地），类型 int。定义：自底向上处理后，表示从 (i,j) 出发到三角形底部的最小路径和（含当前格数值）
维护：处理完第 i 行后，该行每个位置已是「往下走最优」的累计和
更新：triangle[i][j] += min(triangle[i+1][j], triangle[i+1][j+1])，从倒数第二行向上逐行填

变量 i，类型 int。定义：当前正在「压缩」的行号，自底向上
维护：i 从 n-2 递减到 0，最后一行无需更新
更新：每轮处理完一行所有 j 后 i -= 1

变量 j，类型 int。定义：第 i 行上的列下标，范围 0 .. i
维护：同一行内各 j 的更新只读下一行 i+1 的两个邻居，互不覆盖
更新：从左到右或任意顺序遍历 j 均可（因为只依赖尚未改动的 i+1 行）

变量 dp[i][j]（显式表），类型 int[][]。定义：从 (i,j) 到最底行的最小路径和（不修改输入时的等价语义）
维护：dp[n-1][j] = triangle[n-1][j]；向上递推取两子 min
更新：答案为 dp[0][0]；可压成一行 O(n) 额外空间

落码步骤如下。

1. 取 n = len(triangle)；若 n == 1 直接返回 triangle[0][0]

2. 从 i = n-2  downto 0 遍历每一行

3. 对每个 j in range(i+1)：triangle[i][j] += min(triangle[i+1][j], triangle[i+1][j+1])

4. 全部行处理完后，顶点的值即为自顶向下最小路径和

5. 返回 triangle[0][0]

复杂度分析。时间复杂度 O(n²)（n 为三角形行数），空间复杂度 O(1)（自底向上原地修改 triangle）。

常见坑点，请注意。

&#x2757; 递推方向反了：自顶向下需要尚未算出的 f(i+1,*)，易写错边界；自底向上时最后一行不要参与内层 min，循环应从 n-2 开始。

&#x2757; 下标混淆：第 i 行只有 i+1 个元素，内层 j 上界是 i（含），访问下一行时用 j 与 j+1，不能当成矩形网格的 dp[i][j-1]。

&#x2757; 与 #64 最小路径和混用递推：本题是三角形两岔 min，不是矩形「上/左」；负数路径和仍用 min，不要误用 max 或绝对值。
