题目描述。给定一个非负索引 rowIndex，返回「杨辉三角」的第 rowIndex 行。
在「杨辉三角」中，每个数是它左上方和右上方的数的和；每行首尾元素均为 1。
0 ≤ rowIndex ≤ 33。

示例。示例 1

    输入：rowIndex = 3。示例 2

    输入：rowIndex = 0。示例 3

    输入：rowIndex = 1

先模拟答题者的思考过程，从暴力解法出发，找到重复劳动，再推导优化方向。

1. 暴力：像 #118 一样从第 0 行一直生成到第 rowIndex 行，存整个三角或只留最后一行——正确，但若每层开新数组会多占空间。

2. 重复在哪里？我们只需要最后一行，每一层的新行只依赖上一层相邻两数；上一层数据在算完当前层中间位后，旧左邻值会被覆盖，所以从左往右原地加会破坏尚未使用的 row[j-1]。

3. 优化：用一个数组 row 表示「当前行」，每向下一层：先从右到左做 row[j] += row[j-1]，再在末尾补 1；循环 rowIndex 次即得目标行。手推 rowIndex=3：[1]，得到[1,1]，得到[1,2,1]，得到[1,3,3,1]。

4. 共约 1+2+…+rowIndex 次更新，时间 O(rowIndex²)；除输出外只保留一行，空间 O(rowIndex)。

接下来是变量语义，先理解每个变量的定义、维护和更新，再开始编码。

变量 row，类型 list[int]。定义：当前已构造到第 r 行的杨辉行，长度 r+1，且满足递推关系
维护：每轮外层循环结束，row 表示多了一行后的正确结果；首尾恒为 1
更新：由上一长度的 row 原地递推中间位并 append(1)，或每轮重建新行

变量 r，类型 int。定义：外层循环变量，表示正在从第 r-1 行推到第 r 行
维护：r 从 1 递增到 rowIndex
更新：每轮 r += 1，直到 row 即为第 rowIndex 行

变量 j，类型 int。定义：内层下标，用于更新第 r 行的中间元素
维护：原地法时 从右向左 遍历，避免覆盖尚未使用的旧 row[j-1]
更新：row[j] = row[j] + row[j-1]（j 从 r-1 降到 1）

落码步骤如下。

1. 初始化 row = [1]（第 0 行）

2. 若 rowIndex == 0 直接返回 row

3. 对 r = 1 .. rowIndex：内层 j 从 r-1 递减到 1，执行 row[j] = row[j] + row[j-1]

4. 每层结束 row.append(1) 作为新行末尾的 1

5. 返回 row（长度 rowIndex+1）

复杂度分析。时间复杂度 O(rowIndex²)，空间复杂度 O(rowIndex)（只存当前一行；输出长度 rowIndex+1）。

常见坑点，请注意。

&#x2757; 原地更新方向错误：从左到右做 row[j]+=row[j-1] 会先把左边的旧值改掉，后面位置算错；必须从右向左。

&#x2757; 忘记每层末尾补 1：只更新中间位会导致行长度仍为 r 而非 r+1，输出缺最后一个 1。

&#x2757; 循环上界 off-by-one：应执行 rowIndex 次「向下一层」递推（r 从 1 到 rowIndex）；若只循环到 rowIndex-1 会少一行。
