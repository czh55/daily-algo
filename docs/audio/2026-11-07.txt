题目描述。给你一个整数数组 prices，其中 prices[i] 表示某支股票第 i 天的价格。
在每一天，你可以决定是否购买和/或出售股票。你在任何时候 最多 只能持有 一股 股票。然而，你可以在 同一天 多次买卖该股票，但要确保你持有的股票不超过一股。
返回你能获得的 最大 利润。

示例。示例 1

    输入：prices = [7,1,5,3,6,4]。示例 2

    输入：prices = [1,2,3,4,5]。示例 3

    输入：prices = [7,6,4,3,1]

先模拟答题者的思考过程，从暴力解法出发，找到重复劳动，再推导优化方向。

1. 暴力：枚举起买、止卖日组合（多笔、不重叠且先买后卖），状态空间巨大，O(2ⁿ) 级，不可行。

2. 重复在哪里？任意一笔跨多天的盈利 prices[sell] - prices[buy]，可拆成连续若干天「昨日买、今日卖」的价差之和，且只有上涨日贡献正利润。

3. 贪心关键：最大化总利润 ⇔ 把所有相邻上涨的价差全部收入囊中——下跌日不买不卖，等价于跳过负贡献。

4. 与 #121 对比：#121 至多一笔；本题可多次交易，但「同一天先卖后买」允许，故每一段上涨都能独立结算，一次扫描累加即可。

5. 等价 DP 视角：hold / cash 两状态转移也能 O(n)，但贪心累加相邻正差更短、更直观。

接下来是变量语义，先理解每个变量的定义、维护和更新，再开始编码。

变量 ans，类型 int。定义：在允许多笔交易、同时最多持有 1 股的前提下，累计可获得的最大利润
维护：初值 0；只累加「正利润」的价差片段
更新：相邻两天价差为正时 ans += prices[i] - prices[i-1]（等价于吃掉每一段上涨）

变量 prices[i]，类型 int。定义：第 i 天的股价，与前一天比较刻画「本日相对昨日的涨跌」
维护：从左到右扫描，仅需相邻两天 (i-1, i)
更新：当 prices[i] > prices[i-1] 时，认为在昨日买、今日卖能无风险地赚到这段涨幅

变量 diff，类型 int。定义：单日边际利润 diff = prices[i] - prices[i-1]
维护：每步只依赖当前与前一价格，不需显式记录持仓
更新：if diff > 0: ans += diff；下跌或持平则 diff ≤ 0 不累加

落码步骤如下。

1. 初始化 ans = 0

2. 从下标 1 遍历到 n-1

3. 计算 diff = prices[i] - prices[i-1]

4. 若 diff > 0，则 ans += diff

5. 返回 ans

复杂度分析。时间复杂度 O(n)，空间复杂度 O(1)。

常见坑点，请注意。

&#x2757; 勿与 #121 混淆：本题可多笔交易，不能只用「全局最低买一次」；要把每段上涨都算上。

&#x2757; 只有 diff > 0 才累加；持平或下跌不加，否则会做出「高买低卖」的负利润。

&#x2757; 循环从 i=1 开始：单元素数组无相邻日，应直接返回 0。

必测的边界情况。

Case 1：单天

Case 2：单调上涨

Case 3：单调下跌

Case 4：震荡上升

Case 5：相邻持平
