题目描述。给你一个链表的头节点 head 和一个特定值 x ，请你对链表进行分隔，使得所有 小于 x 的节点都出现在 大于或等于 x 的节点之前。
你应当 保留 两个分区中每个节点的初始相对位置。

示例。示例 1

    输入：head = [1,4,3,2,5,2], x = 3。示例 2

    输入：head = [2,1], x = 2

先模拟答题者的思考过程，从暴力解法出发，找到重复劳动，再推导优化方向。

1. 我先写暴力：把链表所有值拷进数组，按是否 <x 分成两段再重建链表——正确且能保留相对顺序，但多用了 O(n) 额外数组，也没利用「只改指针」这一链表优势。

2. 重复在哪里？题目不要求排序，只要求「小于 x 的在前、其余在后，且各段内相对顺序不变」——等价于稳定地把节点分成两桶，再头尾相接。

3. 双桶尾插：维护 small 与 large 两条链，各配哨兵 + 尾指针；扫原链时，节点直接挂到对应桶尾部（尾插保证桶内顺序与原链一致）。

4. 扫完后把 large 头接到 small 尾后；务必令 large_tail.next = None，否则原链末尾可能仍指向旧后继，形成环。

5. 每个节点只访问一次，时间 O(n)；仅常数个指针，空间 O(1)（不计返回链表本身）。

接下来是变量语义，先理解每个变量的定义、维护和更新，再开始编码。

变量 small_dummy / large_dummy，类型 ListNode*。定义：两条结果链表的哨兵头，不存有效值
维护：分别锚定「<x 段」与「≥x 段」的起始位置
更新：创建后不再移动，最终用 small_dummy.next 作为答案头

变量 small_tail / large_tail，类型 ListNode*。定义：两条分区链表的尾指针
维护：始终指向各自已拼接部分的最后一个节点
更新：每接入一个节点后 tail = tail.next

变量 curr，类型 ListNode*。定义：原链表中当前待分类的节点
维护：从 head 沿 next 扫完整条链
更新：每轮先按 curr.val 挂到对应尾后，再 curr = curr.next

落码步骤如下。

1. 创建 small_dummy、large_dummy，尾指针 small_tail、large_tail 初始指向各自哨兵

2. curr = head，当 curr 非空：若 curr.val < x 挂到 small 桶尾，否则挂到 large 桶尾；curr = curr.next

3. large_tail.next = None（截断 large 段，防环）

4. small_tail.next = large_dummy.next，返回 small_dummy.next

复杂度分析。时间复杂度 O(n)，空间复杂度 O(1)。

常见坑点，请注意。

&#x2757; 忘记 large_tail.next = nullptr：原链表最后一个节点的 next 可能仍指向后续节点，拼接后会形成环或多余节点。

&#x2757; 比较条件写错：题目是「严格小于 x」进前段，val == x 应进后段（≥x）。

&#x2757; 用头插法建桶会破坏「相对顺序」——必须用尾插，与遍历顺序一致。

必测的边界情况。

Case 1：空链表

Case 2：全部 <x 或全部 ≥x

Case 3：x 与节点值相等
