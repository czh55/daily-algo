题目描述。给你一个字符串 s，请你将 s 分割成一些子串，使每个子串都是回文串。
返回符合要求的最少分割次数（切刀数：整串已是回文则返回 0）。
1 ≤ s.length ≤ 2000，s 仅由小写英文字母组成。

示例。示例 1

    输入：s = "aab"。示例 2

    输入：s = "a"。示例 3

    输入：s = "ab"

先模拟答题者的思考过程，从暴力解法出发，找到重复劳动，再推导优化方向。

1. 我先想暴力：像 #131 一样回溯枚举所有切法，记录切刀数取最小——正确但 n≤2000 时 2^n 完全不可行。

2. 重复在哪里？对后缀 s[i..] 来说，第一刀落在哪、后面又是「后缀最小切分」同一子结构；不同切法会重复解同一 s[j+1..]，应记忆化而非 DFS 裸搜。

3. 定义 cuts[i] = s[i..n-1] 的最少切刀数。枚举第一段为 s[i..j]（须回文）：若这一段已是整串后缀，代价 0；否则这一刀加上 cuts[j+1]。取最小即最优子结构。

4. 回文判断不能每次 O(n)：复用 #131 的 is_pal 预处理 O(n²)，DP 再 O(n²)。手推 s="aab"：cuts[2]=0（"b"）；cuts[1] 只能 "b"|"?" 得 1；cuts[0] 试 "a"|… 得 2、"aa"|"b" 得 1 ，得到 答案 1。

5. 填表顺序：i 从 n-1 递减到 0，计算 cuts[i] 时 cuts[j+1]（j<n-1）已就绪。

接下来是变量语义，先理解每个变量的定义、维护和更新，再开始编码。

变量 is_pal[i][j]，类型 bool[n][n]。定义：s[i..j] 是否为回文
维护：与 #131 相同，预计算后全程只读
更新：按区间长度递增填表：s[i]==s[j] 且（长度 ≤2 或 is_pal[i+1][j-1]）

变量 cuts[i]，类型 int[n]。定义：子串 s[i..n-1] 切成全回文段的最少切刀数
维护：从右向左填；答案为 cuts[0]
更新：枚举第一段终点 j（s[i..j] 为回文）：若 j==n-1 则代价 0，否则 1 + cuts[j+1]；cuts[i] 取各合法 j 的最小值

变量 j，类型 int。定义：当前尝试的第一段回文子串的右端点下标
维护：对每个起点 i，j 从 i 枚举到 n-1
更新：仅当 is_pal[i][j] 才参与松弛 cuts[i]

落码步骤如下。

1. 记 n = len(s)，建 is_pal[n][n]（与 #131 相同双重循环按长度填表）

2. 初始化 cuts = [0] * n；cuts[n-1] = 0（单字符后缀无需切）

3. 对 i 从 n-2 到 0：cuts[i] = n（哨兵），再枚举 j 从 i 到 n-1

4. 若 not is_pal[i][j] 跳过；否则 cost = 0 if j == n-1 else 1 + cuts[j+1]，cuts[i] = min(cuts[i], cost)

5. 返回 cuts[0]

复杂度分析。时间复杂度 O(n²)（预计算回文表 O(n²) + 后缀 DP 每层枚举切点 O(n²)），空间复杂度 O(n²)（回文 DP 表 + 一维 cuts 数组）。

常见坑点，请注意。

&#x2757; 把「段数」当「切刀数」：整串回文应返回 0，不是 1；一段后缀对应 0 刀，多段才加切刀。

&#x2757; j == n-1 时忘记代价为 0：写成 1 + cuts[n] 会越界或多算一刀。

&#x2757; cuts[i] 必须从大到小填：若从小到大，cuts[j+1] 可能尚未计算，子问题顺序错误。
