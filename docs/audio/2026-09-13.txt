题目描述。给定一个字符串 s，返回 s 是否是一个有效数字。
例如，下面的都是有效数字："2"、"0089"、"-0.1"、"+3.14"、"4."、"-.9"、"2e10"、"-90E3"、"3e+7"、"+6e-1"、"53.5e93"、"-123.456e789"，而接下来的不是："abc"、"1a"、"1e"、"e3"、"99e2.5"、"--6"、"-+3"、"95a54e53"。
有效数字可由「整数 + 可选指数」或「小数 + 可选指数」构成；指数部分为 e/E 后跟整数。

    输入：s = "0"。示例 2

    输入：s = "e"。示例 3

    输入：s = "."

先模拟答题者的思考过程，从暴力解法出发，找到重复劳动，再推导优化方向。

1. 最直接：用正则或语言内置解析（如 Python float(s)）——面试/竞赛通常不允许，且手写正则极易漏边界（如 "4."、"-.9"）。

2. 重复在哪里？每读一个字符，「当前已读前缀是否仍可能是有效数字的一部分」只取决于当前所处阶段（有没有符号、整数、小数点、指数等），与更早细节无关——适合有限状态机。

3. 拆成 8 个状态：起始(0) ，得到 可选符号(1) ，得到 整数(2) ，得到 仅点(3) ，得到 小数(4) ，得到 指数 e(5) ，得到 指数符号(6) ，得到 指数整数(7)。合法结尾必须是 2、4 或 7（至少读过一位数字）。

4. 手推 "-.9"：'-' 0，得到1，'.' 1，得到3，'9' 3，得到4，结束 state=4 ∈ VALID ，得到 true。手推 "1e"：'1' 0，得到2，'e' 2，得到5，结束 state=5 ∉ VALID ，得到 false。

5. 也可用 seen_digit / seen_dot / seen_e 三旗标逐字符模拟，但状态机转移表更不易漏 case；本题困难主要体现在边界枚举完整。

接下来是变量语义，先理解每个变量的定义、维护和更新，再开始编码。

变量 state，类型 int。定义：当前解析所处的 DFA 状态（0 起始 ，得到 1 已见符号 ，得到 2 整数 ，得到 3 仅小数点 ，得到 4 小数 ，得到 5 已见 e ，得到 6 指数符号 ，得到 7 指数整数）
维护：每读一个字符，按转移表查下一状态；非法转移置 -1
更新：遍历完整个字符串后，state ∈ {2, 4, 7} 才为有效数字

变量 TRANS[state]，类型 dict。定义：状态转移表，键为字符类别（sign/digit/dot/e）
维护：编码题目规则——如状态 2 可读数字/小数点/指数，状态 3 只能接数字（".5" 型）
更新：只读常量，不随输入改变；当前字符映射到类别后查表得下一 state

变量 c，类型 char。定义：当前扫描的字符
维护：按 +-、eE、.、数字四类分发到转移键
更新：从左到右逐字符处理，遇未知字符直接返回 false

变量 VALID，类型 set。定义：合法终态集合 {2, 4, 7}（纯整数、小数、带指数）
维护：状态 1/3/5/6 不能作为结尾——如 "+"、"."、"1e"、"1e+" 均非法
更新：遍历结束后用 state in VALID 判定

落码步骤如下。

1. 定义 8 行转移表 TRANS 与合法终态 VALID = {2, 4, 7}

2. state = 0，从左到右遍历 s 每个字符 c

3. 将 c 映射为类别：数字 ，得到 digit，+- ，得到 sign，. ，得到 dot，eE ，得到 e；未知字符返回 false

4. state = TRANS[state].get(类别, -1)，若为 -1 说明非法转移，返回 false

5. 遍历结束后返回 state in VALID

复杂度分析。时间复杂度 O(n)，空间复杂度 O(1)。

常见坑点，请注意。

&#x2757; 终态判断遗漏：仅 "+"、"."、"1e"、"1e+" 等中间态不能返回 true，必须 state ∈ {2,4,7}。

&#x2757; 指数后不能再有小数点："99e2.5" 在读到 . 时状态 7 无 dot 转移，应判 false。

&#x2757; 符号位置错误："--6"、"-+3" 在状态 2 遇到第二个 sign 无转移；指数符号只能在状态 5 后出现，不能出现在整数中间。

Case 2：仅指数符号

Case 3：仅小数点

Case 4：点前无整数

Case 5：整数后单独小数点

Case 6：指数缺整数
