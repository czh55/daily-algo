题目描述。如果在将所有大写字符转换为小写字符、并移除所有非字母和非数字字符之后，短语正着读和反着读都一样。则可以认为该短语是一个 回文串 。
字母和数字都属于字母数字字符。
给你一个字符串 s，如果它是 回文串 ，返回 true ；否则，返回 false 。

示例。示例 1

    输入：s = "A man, a plan, a canal: Panama"。示例 2

    输入：s = "race a car"。示例 3

    输入：s = " "

先模拟答题者的思考过程，从暴力解法出发，找到重复劳动，再推导优化方向。

1. 我先按题意预处理：过滤出所有字母数字、转小写得到字符串 t，再判断 t == t[::-1]——正确，但要额外 O(n) 空间存 t，长度可达 2×10⁵。

2. 重复在哪里？回文只要求「对称位置上的有效字符」相等，标点与空格从不参与比较，不必真的删掉它们。

3. 双指针：两端向中间走，各指针先向内跳过非字母数字，再比较小写后的字符；全部配对成功即为回文。

4. 为什么跳过合法？当 l 还在 r 左侧时，被跳过的字符在回文意义上没有「对称搭档」，不影响已配对部分的正确性。

5. 空有效串（如示例 3）：指针相遇或交叉前未出现不等比较，循环正常结束，返回 true。时间 O(n)（每字符最多被两个指针各访问一次），空间 O(1)。

接下来是变量语义，先理解每个变量的定义、维护和更新，再开始编码。

变量 l，类型 int。定义：从左侧找到的、下一个待参与比较的字母数字字符下标
维护：初始 0；若当前字符非字母数字则右移，直到 s[l] 有效或 l >= r
更新：一轮比较成功后 l += 1

变量 r，类型 int。定义：从右侧找到的、下一个待参与比较的字母数字字符下标
维护：初始 len(s) - 1；跳过非字母数字则左移
更新：比较成功后 r -= 1

变量 norm(c)，类型 char。定义：将字母数字字符统一为小写（或等价比较）后的规范形式
维护：只对 isalnum 为真的字符调用
更新：每对 (l, r) 比较 norm(s[l]) 与 norm(s[r])，不等则立刻返回 false

落码步骤如下。

1. 令 l = 0，r = len(s) - 1

2. 当 l < r：内层循环使 s[l] 为字母数字，否则 l++；同理调整 r

3. 若仍 l < r 且 tolower(s[l]) != tolower(s[r])，返回 false

4. 否则 l++、r--，继续下一对

5. 循环结束返回 true

复杂度分析。时间复杂度 O(n)，空间复杂度 O(1)。

常见坑点，请注意。

&#x2757; 大小写：必须统一成小写（或 tolower）再比较，'A' != 'a' 若不做规范化会误判。

&#x2757; 跳过非法字符时也要检查 l < r，否则指针交叉后仍访问会越界或重复比较。

&#x2757; 数字参与回文：'0'、'1' 等算字母数字字符，isalnum 为真；勿只处理字母。

Case 4：首尾不对称
